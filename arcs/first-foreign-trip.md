# 第一次外国旅行

## 当前范围

第206—221章。弥珞一行第一次正式出国，进入西部的维尔兰联邦，并在塔温港官方成人行程结束后，以私人旅行身份短暂前往独立的岬灯自由市；第221章返抵灰岭，第一次外国旅行完整收束。

## 已发生

- 第206章：跨越国境；第一次从铁路、城市天际线与大型工业基础设施中感受到另一种现代性。赫尔辛格以蒸汽与魔法的深度融合、大型集中系统和长期维护文化为显著特征；夜间第一次体验工业谜剧《第七码头最后一声汽笛》。
- 第207章：进入赫尔辛格中央蒸汽与魔能总厂，看到蒸汽总网、轮机、复合飞轮、气动固定计算、独立脉冲警报、工人技术档案和工业娱乐设计；夜间进入第二场谜剧《王冠不在保险柜里》。
- 第208章：完成《王冠不在保险柜里》。谜题核心不是“找到失窃王冠”，而是证明王冠早已合法移交、失窃叙事在事件发生前已经被安排。人物通过合同、排版时间、气动邮政、器物结构、植物痕迹和时间线协作还原事实。
- 第209章：离开赫尔辛格前往洛恩桥。第一次完整体验维尔兰当地公共交通：蓄汽街车、联邦区域蒸汽快车、维桑河谷高压蓄汽支线、齿轨辅助与洛恩桥坡道缆车。赫尔辛格的大型中央蒸汽体系逐渐从窗外退去，洛恩桥以街区动力站、余热互换、可移动蓄汽、坡地交通和大量旧桥构成另一种工业现代性。弥珞与诺芙在途中有更明显但仍自然的恋人亲密；瑟弥娅与弥宁继续以各自方式观察交通、地图与生活。
- 第210章：进入洛恩桥东区分散动力联合体系。通过东三站计划性维护，看到街区动力站、跨区换供、移动蓄汽、低温热储、公共互助与中断赔偿如何共同维持城市；同时明确分散系统的代价：维护人员更多、计量/合同关系复杂、街区能力与热价不均，不能把“分散”写成天然正确。下午访问桥下七号仪表社与小型机床工坊，理解洛恩桥精密压力仪表为何从大量街区尺度需求中生长出来；学生组则绘制街区动力关系图，发现行政、供热与历史行业边界并不重合。晚间乘西坡晚线进入旧桥区，工业奇观与普通夜生活重合；弥珞与诺芙的恋人关系在旅行中更自然、更主动地展开。
- 第211章：南岸精密制造联合区发生事先公告的二十分钟联合“停手”。争议并非简单反对自动化，而围绕自动批次调度、自校压力总成上线后夜班人数、跨厂区异常接管上限、培训与转岗资金等具体问题。弥珞第一次亲眼看见机器完全没有故障、工业系统也能安全运行，但工人主动把手从控制杆上拿开；她拒绝以外国技术名人身份替当地劳资关系给出“该不该上”的答案。停手前后的准备、安静与恢复本身构成工业景观，也让学生组开始把“谁有权停、哪些岗位不能停、停以前谁必须先做什么”纳入基础设施时间图。谈判尚未结束，访问团不会在离开前得到整齐答案。
- 第212章：离开洛恩桥，经沿河旧工业线前往塔温港。河运、自由港识别旗、多语车站与跨境商品开始把“世界比国家大”变成具体经验。塔温港晚雾导致公共渡轮停航，一行人改乘七号环线蒸汽电车；在旧商埠区偶然进入六号公共剧场，看八十多年历史的地方旧戏《潮门》港口新版。戏中潮闸建设、机械装卸、老渡船、家庭收入、地租与个人去留没有被压成单一反派，人物各自有合理却互相冲突的处境；舞台与历史放映画面并置，让同一座港口的两个时间互相照见。弥珞开始真正理解“事情不坏、没有反派，也仍然可以成为故事”。夜间在外国书摊买到《灰岭三首短诗及北部地区新诗选》，看到本国地方诗歌已经通过放映、出版和贸易先她一步抵达外国。
- 第213章：塔温港雾散，一行人第一次真正面对外海。公共蒸汽渡轮、远洋蒸汽辅帆船、港口引航、跨境货物标签与不同标准之间的转接关系，让“国际”从旗帜与地图落到具体责任链。旧引航员讲起已经拆除六十一年的“第八码头”：官方记录只保留雾中废止信号“一长两短”，船员日志、工人口述、儿童顺口溜和酒馆歌却各自长出不同版本。下午低雾中众人真的听见八码头方向的一长两短信号，现役船没有对应发送，原因仍未确认；港务系统照常留下正式记录，而故事继续在民间分叉。弥宁从测绘角度意识到“名字没死”：八码头已不再是现役泊位，却仍作为水下基础、禁锚区和口语地名影响现代空间。瑟弥娅得到一本《塔温港异闻十七则》，进一步区分档案、史料、口述与故事并不需要被强行统一。
- 第214章：弥珞、诺芙、瑟弥娅等乘普通“海门七号”公共航线前往外港引航站，第一次真正驶出防波堤。通过普通船票、蓄汽/蒸汽动力、旅客状态牌、海上靠泊、灯塔、引航员登临远洋船等具体经验，弥珞第一次意识到海上的“路”并不长在水面，而存在于测量、灯、浮标、潮表、图、经验、责任与共同约定中。章节以喜悦、新奇和身体经验为主，不将第一次出海压成技术结论；弥珞与诺芙也进一步确认“以后可以一起去更远，但不必每次绑定行程”。
- 第215章：切换为弥宁第一人称。学生组在塔温港教学岸段进行同一地点低潮、中潮、高潮三次测绘，所有成果明确盖有“教学测绘，不得用于航行”，坚持学习不等于免费劳动。弥宁从水尺、施工潮记、盐生植物、旧警示牌、可站边界和小艇坡道中理解：岸线不是某次看到的水边，而是必须说明时间、用途与参照定义的关系。她开始更明确拥有独立于姐姐的观察与知识路径；姐妹当天没有替对方看见，却能在晚上交换各自的第一次。
- 第216章：成人官方交流日程结束，访问联络表第一次要求弥珞自己填写“预计离开维尔兰日期”。她选择“待定”，并意识到如今不知道返程日期已不再是十九岁时轻飘飘的单程票，而与家、工作、妹妹课程、同伴时间和现实交通连接在一起。塔温港放映与出版联合馆让翻译、本地化和跨境文化传播进入生活；随后一行人在私人时间发现三小时船程外的岬灯自由市，并自费购买普通国际客货船票。
- 第217章：切换瑟弥娅第一人称。她第一次以自己的现代旅行证件、私人观光和“学生 / 兼职技术史协作”身份进入另一个独立政治体，不靠古代王室头衔通行。岬灯自由市以陡坡、狭小港池、海风、潮差、雨水收集、坡岸升降与层叠街道形成不同于维尔兰工业城的地方生活。瑟弥娅在旧灯塔下寄出一张普通跨境明信片，主动告诉灰岭的家人“我今天在哪里”，并进一步确认现代的“回家”不是别人允许她返回，而是她已经拥有自己的房间、物件和关系。
- 第218章：岬灯第二天完全作为私人购物与闲逛日。雨棚市场把全球原料、地方加工、坡地物流、淡水与海风等条件揉进普通商品；一行人不再只买技术资料，而真正为自己和家人挑选会进入日常生活的物品。弥珞遵守弥宁“买一个没有学习用途的东西”的要求，最终选择一只明确不能测风、只负责好看的海绿色玻璃“小潮鱼”；她还买了灰蓝短风衣、送诺芙深海蓝防风围巾，并给自己买一枚不知道有什么用途的旧玻璃纽扣。瑟弥娅主动突破自己惯常冷色，买了姜黄色防水肩袋；雷奥妮、伊莱娅也各自按自己的性格购物。大件与食品通过跨境合包寄往灰岭，小潮鱼由弥珞亲自携带。
- 第219章：众人乘九时二十分《海榆》返回塔温港，与完成最后交换汇报的学生组重新汇合。弥珞把“小潮鱼”亲手交给弥宁，并坚持它继续“什么都不会”。洛恩桥南岸传来六个月试运行备忘录的阶段性后续；当天晚上全员购买次日下午十五时四十分返程联运票，弥珞把离境表“待定”改成具体日期。
- 第220章：切换诺芙第一人称。返程跨境卧车夜间经过赫尔辛格外环，次日下午在西境联运站完成维尔兰出境、王国入境与车辆换挂。普通二手玻璃纽扣凭购买凭证顺利过关；两国干线牵引技术差异通过换车头自然显现。诺芙第一次完整地从“陪一个人回家”的角度理解：她不需要拥有弥珞十九岁出发时那张单程票，也能参与如今的返程。
- 第221章：列车晚七分钟抵达灰岭中央站。一行人以普通公共交通回家，豆包先闻人再选择蹭谁；第一餐只是出门前冻好的家常汤。家庭旅行记忆层在原地图西侧增加透明延伸片，记录赫尔辛格、洛恩桥、塔温港、岬灯与海路。返程票已经用完，但人物、物件、关系与对世界的理解没有返回原样；第一次外国旅行正式结束。

## 主题

- 外国不是技术景观或“异国主题公园”，而是别人真正生活、工作、维护、娱乐、购物、送礼和回家的社会。
- 维尔兰不能被简化成“蒸汽朋克”：蒸汽是热水、医院、工厂、住房、劳动制度、交通与城市历史。
- 同一联邦内部也不存在唯一技术路线。赫尔辛格像“一副巨大的胸腔”，洛恩桥则把动力拆成许多街区尺度的“小风箱”；规模差异来自资源、地形、历史与治理习惯，而不是先进/落后二分。
- 分散不等于各自独立。系统拆得越小，互供、计量、责任、合同、公共兜底和跨区协调可能越复杂；技术自治不能被写成公共责任退出。
- 自动化的社会后果不能被压成“机器抢工作”或“技术进步必然胜利”。减少危险与枯燥劳动、岗位数量、责任集中、技能传承、工资、培训、工时和谁有权拒绝继续接管可以同时构成真实争议。
- “正常运行”是技术状态，也可能包含人的同意、承受和停下来的权利；机器能继续运行，不意味着人必须继续把手放在上面。
- 技术社会也是文学社会。《潮门》把地方工业史、家庭、劳动与城市更新揉进戏剧，不靠反派替矛盾收口；放映设备让旧戏获得“舞台现在 / 档案过去”并置的第二层时间。
- 地方文化不是单向从王都或大中心向外传播。灰岭诗歌能抵达塔温港，海边小剧团也能进入王都；传播网络让边缘彼此看见，而不是只有中心向地方发内容。
- 港口让“志怪/异闻”重新获得现代位置：未知现象可以被工程系统记录、被地方人讲述、被儿童押韵、被酒馆改唱；记录要求证据边界，故事可以保留分叉，两者都不必吞掉对方。
- 海上交通进一步改写“路”的意象：没有可见轨道不等于没有基础设施；有些路主要存在于知识、测量、共同规则和持续判断中。
- 弥宁的测绘线进一步独立。地图不是世界本身，岸线、道路、责任和可用状态都必须说明自己按什么参照成立；可靠不只意味着不动，也可以意味着知道自己为什么会动。
- 私人旅行与购物也能推进人物。礼物不是“把地方占有一点”，而是提前想象东西回家以后怎样被使用、遗忘、弄旧；旅行纪念品真正进入生活以后，往往会失去“纪念品”的端正状态。
- “没有返程日期”不等于永远不订票。人物可以拥有明确返程票、离境日期和到站时刻；真正无法返回的是出发前的自己、世界与关系原状。
- 返程不是去程的倒放。看过、学过、喜欢过、争论过的地方会在回程车窗里变成“已经认识一点”的地方；普通本国文字、食物和空气也会因为离开过而短暂发亮。
- 旅行本身继续成为正文，而不是只为技术会议提供转场。车窗、雾、票、食物、普通乘客、临时改线、戏票、书摊、船、市场、衣服、礼物、汽笛、海风和恋人之间的身体距离都属于世界的一部分。

## 后续余波

- 岬灯跨境合包预计比人物晚十到十四天抵达灰岭；瑟弥娅寄出的明信片也可能在人已经回家后才到。后续可以用拆包、食物、书、碗、衣物等日常方式让旅行继续留下余波。
- 第八码头异闻继续保持“未确认”，不因为旅行结束而关闭。第300章把它推进一层：塔温港冬季旧港基础低潮检修时，维护人员对一段确认与现役系统隔离的旧信号支路做低压气密检查，降压过程中由残存管路、未编目小容积、积水与末端条件共同形成一次可记录的“一长两短”样声响；改变条件后声型发生变化。该结果只证明残存旧管在特定人工条件下**能够**产生类似废止号型，不解释第213章十四时四十二分那次无对应低压测试/吹扫记录的异常，也不回填六十一年来其他口述与记录。未知从“旧管是否物理可能发声”缩小为更具体的条件问题，但历史事件仍保持原证据边界。
- 第310章继续回收洛恩桥南岸的联合试行，但只推进培训可得性这一小块。第232章锁定培训预算、保留课程与带薪训练以后，几家小厂仍会因为专业人员缺口、生产覆盖和维修复机需求，把已经排好的培训者临时叫回车间；“预算已提供 / 课程已开”因此不能自动等于工人真正获得训练时间。冬季过程记录开始把**实际带薪释放时数**单独记录，并在若干自愿参与工厂中把“带薪培训释放”写入自动调度：对应时段不再计入普通生产覆盖和日常异常接管可用人数，真正安全事件仍可按明确程序中断。资格相容时可用预先登记的联合后备人员覆盖部分通用岗位；资格不能互换时则允许延后批次、增加现场班次、调整课程并留下原因，或暂时降低部分自动调度强度，而不是把培训者默认成随时可召回的隐形产能。该做法仍只是有限试行，扩班成本、远程接管上限、共享替班成本、疲劳折算和长期岗位安排都没有终局。
- 未来真正跨海仍只是愿望。岬灯属于成熟三小时短航线上的近邻自由市，不等于已经完成远洋旅行。
- 第221章后应先允许人物真正回到灰岭生活：休息、买菜、洗车、拆包、恢复工作和学校节律。新的大旅行不必立刻发生。
