# 灰岭

故事弧索引。记录弥珞在灰岭的停留、工作、家庭生活与地方技术协作。

## 第一次外国旅行归来以后

- 第221章完成第一次维尔兰/岬灯旅行的返程：人物回到灰岭，但旅行留下的技术、物件、关系和未完成问题继续存在。
- 第222章把“回家”从返程票落回日常生活。弥珞与诺芙开远湾去洗车、买菜，因旧学院路交通调整绕行旧货运支线，重新从陌生化视角看灰岭。市场里的季节变化、本地物流和由开放接口衍生出的非机械社显文牌，让弥珞第一次明显感到：城市与技术都能在她不在时自己继续生长。
- 弥珞开始更稳定地做到“看见有趣的东西，不等于立刻开项目”；诺芙与弥珞的恋人关系继续自然嵌入日常动作。瑟弥娅以现代学生身份继续上课，弥宁把塔温港三次潮位测绘整理为自己的学校分享。
- 家庭物质痕迹继续累积：岬灯灰蓝短风衣、诺芙的深海蓝围巾、瑟弥娅的姜黄色防水肩袋、弥宁的无用途玻璃小潮鱼，以及回家后第一张普通买菜单。
- 第223章弥珞正式回机械社上班。旅行期间建立的去中心化工作结构经受住她十几天不在场：真正留给她的只有低空验证场收费边界、旧设备兼容层是否进入核心、长期跨机构代表席位三项方向性问题。处理完后她又被莫兰阻止把维尔兰旅行笔记立刻扩张成新项目，按正常工时下班。
- 第224章把“别人不需要弥珞”写成一次真实而有张力的专业经验。南市集三号公共冷藏柜出现温控异常，弥珞前一天刚见过该设备，几乎本能地想去现场；但市场设备合作社、食品转移、维护与兼容支持链均正常运作，没有人向她升级。事件最终确认是门体轻微下垂造成机械闭合与实际密封不一致，现场安全转移完成，后续接口扩展只进入普通评审队列。与此同时，弥珞自己的部门正在处理旧照片“候选重建不能伪装成原件”的图像修复边界。
- 第225章切换瑟弥娅第一人称。她收到在岬灯寄出、比本人晚十二天回到灰岭的明信片，并选择把它放进自己的私人抽屉，而不是家庭公共票夹或历史档案。跨境合包同日抵达，两只白底蓝边小碗、食品、书和普通用品真正进入厨房与日常。弥宁也收到塔温港学校寄来的交换反馈。旅行的物件、信件和人并不同步返家，进一步深化“返程能带人回来，但不能把所有时间重新对齐”。
- 第226章继续瑟弥娅第一人称，并把此前长期铺垫的瑟弥娅—涅芙拉感情线正式推进。涅芙拉明确以“不是课”的私人邀请带她去河西旧机务街；两人讨论最初语言/生活支持形成的依赖与今天独立生活之间的区别。瑟弥娅确认自己“即使已经能自己说话、上课、坐车、出国，仍然会想她”，涅芙拉也承认早有私人喜欢。两人第一次明确约会、互相表白、牵手并在询问同意后接吻，确认以“恋人”身份开始交往，同时继续保留各自工作、课程、住处与私人空间。
- 第227章从恋爱线切入一场奇怪的外州矛盾：北榆州月川镇两支家系长期争论是否与瑟弥娅二姐姐一系有关，地方归灯节又在她苏醒后重新被“王女归亲”叙事激活。月川旅游合作会甚至根据地方戏与公开影像，把涅芙拉擅自称作“翼卫”。瑟弥娅拒绝参加未经同意的认亲宣传，也拒绝替两支家系做血缘裁决；她只同意在证据边界明确、记录默认封闭的条件下提供有限历史记忆。
- 第228章切换为月川67岁家系代表第一人称。两支争论多年的家庭与档案馆代表来到灰岭，真正面对一个身体只有20岁的“可能长辈”。一条早于瑟弥娅苏醒就有记录的家族口述“我又不是门”与她关于二姐姐的私人记忆发生对应，成为值得继续研究的新证据，但仍不足以确认血缘。所谓“翼卫”最终查明并非古代礼制，而是九十多年前地方戏《月灯第三女》为了舞台效果创造的“夜翼守者”，后来被旅游宣传错误套到涅芙拉身上。瑟弥娅允许地方戏继续作为地方故事存在，但拒绝让戏剧角色吞掉现实中的人。
- 月川争议没有在灰岭被“解决”。瑟弥娅只决定本人姓名、身份、私人关系与口述材料如何被使用；归灯节是否取消家系轮换、商户与档案馆如何平衡旅游收入和历史诚实、两支家庭如何继续处理自己的七十年争论，都留给月川现代居民自己决定。
- 第232章从镜潮湾返回灰岭后，弥珞终于对学院时代那只玻璃铃做了有限、非破坏测试。测试确认其机械主响应落在历史“中带参照铃”的宽范围，并与定音石常见响应带发生重叠，但没有做破坏性成分取样，也没有强行认定制造来源。这个长期钩子从“神秘会响的玻璃铃”推进为“可能失去说明书的旧式粗巡检器具”，同时保留年代、工坊、技术传播路径与赠铃老妇人的知识来源未知。
- 同一章收到洛恩桥南岸六个月试运行第一阶段备忘录。九家企业进入新的联合夜班规则，三家退出统一方案；规则具体写入异常负荷阈值、远程接管上限、带薪培训、人工扩班触发权和部分效率收益回流。争议仍在继续，没有被写成自动化或工会一方的最终胜利。
- 第258章重新回收第212章塔温港夜间书摊买到的《灰岭三首短诗及北部地区新诗选》。同一选本的维尔兰增订第三印以“王国回售版”重新出现在灰岭中央站书亭，其中把铁路夜班诗里“灯不等车 / 灯不等人”的刊本—放映异文正式标注出来。弥宁自行去学校资料室找到四年前放映目录与来源卡，确认学校所见《灰岭冬灯》使用“灯不等人”，且底稿来自更早公开演出录记并明确注明“不作校勘底本”；公开演出如何形成异文仍未确认。文化传播因此从“灰岭诗先抵达外国”继续推进为“地方刊本—演出—放映—学校—跨境翻译—回售注释”的多向回返，但不能把这条链未经证据的部分画成实线，也不能把流传版本与作者刊本互相抹掉。
- 第289章回收第211、232章洛恩桥自动化—劳动线，但不再以阶段备忘录本身为主角。河湾器材合作社进口三套成熟自校压力总成时，出口王国语说明把南岸“单名值守员最多同时监督两处退化状态”的地方联合夜班协议排成类似机器额定参数。公共认证站区分硬件行为与运行说明；弥珞只说明该数字的历史来源，不替河湾决定排班。实际模拟也表明同样“一处 / 两处”在参考漂移、远端确认、现场距离和并发工作下负荷不同。制造方随后确认出口排版需要修订，且洛恩桥自身已不再把简单数量当成充分条件；小工坊培训仍面临“预算有了、人抽不出来”，正试跨企业临时替班池。河湾不抄洛恩桥旧数字也不抄新版权重，先保持现有两人夜班做四周本地运行记录，再由自己的操作、维护、排班与安全人员复盘。章节进一步确认：跨境成熟产品可以带走金属、接口和手册，但地方劳动协议、值守假设与责任边界不能伪装成机器天然属性。
- 第306章兑现第289章留下的“四周本地运行记录”。河湾内部复盘已经先由自己的操作、维护、排班与安全人员完成，弥珞夜间到场只处理两个状态语义：进口总成把“参考可信下降”和“外部确认超时”都显示成“需复核”，容易让操作员形成不必要的现场奔走；“等待现场”又会把人员已到场、正在隔离和复核的时间误写成无人响应。底层接口本来能区分前两种状态，因此本地准备拆成“本体复核 / 外部确认”；人的到场、隔离、并发外部任务和复核完成则单独留时间戳，不让机器状态替人员行动作全知记录。四周数据没有支持把固定两人夜班改成“一人主值守、一人跨车间备援”，原因不是设备失效，而是后仓供气、旧夹具、不可立即中断的其他工作、临时占道和冬季连廊都会改变第二人的真实可达性。合作社暂时把两人配置保留到冬季结束，同时允许第二位人员在本车间内做可中断工作，并让两人轮流获得可重新补足的完整餐休；自动化当前首先表现为减少重复抄表、无意义来回与记录歧义，而不是自动减少岗位。制造方也已把旧说明书里的“两处退化”从类似额定参数的位置移到“运行组织示例”，明确示例不构成使用地人员配置要求。以上均只属于河湾当前冬季试行与该型号接口，不得外推成全国夜班规则，也不代表春季以后排班已经决定。
- 第308章把第258章的诗歌异文第一次真正放进灰岭当代公共文化生活。弥宁所在学校公开夜把“灯不等车”作者早期刊本与“灯不等人”学校/放映流传版并列展示，不以“选一句正确版本”覆盖另一条传播史；现场旧放映片一度跳片，由学生自己的放映社完成处理。北站一名退休行李房工作人员留下个人回忆，称自己在更早的站内文化活动中已听过“灯不等人”，但当晚只作为口述补记，不据此改写材料年代或异文来源。弥珞在这场活动中只是家属/毕业生观众，克制住当场追问和接管放映设备的冲动。
- 第315章切换诺芙第一人称，回收第314章开头一笔带过的“南片区旧结界护边冻裂”。现场确认裂的是三十多年前后加的硬质保护层，旧结界石本体没有发现需要重新调谐的证据；本地维护班与石作维修员按自己的专业判断做局部拆补和浅排水调整，诺芙只处理许可、关系与档案边界。检修盖上方恰有住户晾晒物，既有后院进入许可并不自动包含移动私人用品的权力，现场因此等待二十三分钟让物主回来自行处理；这段等待被准确记录为“已进入、未获移动同意、等待物主处理”，不事后改写成住户拒绝进入或现场人员尚未到场。住户担心重新维护旧资产会把共用院子永久切成禁用区，现场图因此明确本次占用不形成常设排他范围，日常晾晒、推车和花盆等使用维持现状。该案例只属于灰岭南片区这一处既有维护关系，不升级成全国进入权模板；模板是否需要更通用地区分“进入生效 / 实际占用 / 权限扩大 / 暂停原因”仍只进入候选复核。章节同时推进弥珞—诺芙各自独立工作后的亲密：两人当天分别去北岑与城南，晚上才把“四毫米”和“二十三分钟”带回同一张饭桌，关心不等于必须在场。
- 第324章回收第319章地图上那条“春天以后也许可以去”的西缘地区道路。弥珞与诺芙以完全私人星期日短途出行开远湾前往，出发前已知0—18公里开放、18公里以上仍处春融期封闭，仍选择亲眼走到开放尽头而不把旅行伪装成调查。现场道路巡护显示春融状态并非“山里统一解冻”：向阳表层、背阴冻层、泉口、涵洞、路肩含水和既往修补段需要固定记录与人工巡查共同判断，传感记录用于看趋势而不替代现场劳动；本章不形成新道路技术标准。两人都承认没走到山背会失望，却没有绕行、申请额外权限或把星期日改造成工程项目，而是在十五公里路边铺子吃完午饭、沿已开放河步道散步后按原路返家。家庭地图只把实际走过的记忆线画到十八公里，并写“午饭在这里吃”，不把地图上仍然存在的后续道路冒充成已经抵达；弥珞—诺芙关系继续通过共同期待、失望、吃饭、短吻与各自不替对方管理愿望来推进。
- 第332章继续回收第258、308章“灯不等车 / 灯不等人”异文。第308章公开夜留下口述补记后，那名退休北站行李房工作人员从私人旧物中找到一箱北站文化室材料并自愿捐出大部分纸本。学校资料室先完成第一轮来源登记，再邀请弥珞旁观。箱中一张可由同箱通知、值班材料和纸本特征交叉支持同期使用的蓝色油印短读会节目，比学校四年前放映片的现有来源卡记录早十一年，其中明确印“灯不等人”，旁边还有“末句‘人’拖半拍”的排练批注；这证明至少在该次北站多人排练材料中，“人”不是一个沉默的排字误差，而是被作为表演文本处理。与此同时，同箱更晚读书会材料又按作者早期刊本记“灯不等车”，表明两个版本可在同一站房文化环境中并存。
- 第332章仍不确认异文最初由谁形成。油印纸自己只写“据站内演出本整理”，上一层演出本未见，也没有作者授权、首改者或首次形成日期证据；因此当前链条只能从“学校放映—更早公开演出录记”进一步向前实证到“至少早十一年的北站夜班文化室短读会”，前后未证部分继续用虚线。捐赠者同时收回一枚私人旧储物柜钥匙，学校接受只保存其愿意公开的纸本，明确档案价值不产生对全部私人旧物的占有权。
