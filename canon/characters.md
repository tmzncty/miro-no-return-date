# 人物表

## 弥珞
第一人称主角，猫族；擅长地方结界文献、调谐、测绘及在非标准环境中寻找路径。状态：学院学生 → 专业资格即将失效的毕业生 → 旅行者/地方问题记录者 → 技术与社会协作者。不是天选之人，也不是所有技术的发明者。当前20岁；第一次外国旅行后开始真正形成跨国、跨海视野，但“想去更远”不等于立即把远方变成项目。归来后的新成长重点不是获得更多权力，而是更稳定地接受：城市、机构、年轻工程师和维护链都可以在不需要她的情况下正常工作；有能力帮忙不等于现场自动成为她的职责。

第233—239章进一步把她重新放回“跨专业连接者”位置：赤榛谷车辆术式尾流、公共交换/长距网络与自然史长期观察分别证明，她真正擅长的不是替发动机工程师、网络工程师或自然史学者做完本专业，而是注意到不同专业正在用不同词讨论同一个边界，再帮助建立可验证、可维护、不过度扩张的共同问题。

第343章回收第29章以来长期借用的手摇计算器。机械社资产复核确认它长期由弥珞保管并不等于所有权自动转移；弥珞也没有为了舍不得而虚构持续工作需求，而是先正式归还。该机经基本机械检查、内部继续使用需求核对后进入普通旧资产处置，与同批同状态设备按相同条件出售，弥珞最终使用个人资金购回。此后这台具体计算器属于弥珞的个人物品，但机械社原有资产身份、校验状态与正式现场设备资格不随所有权转移；若未来用于受控专业工作，仍需按当期用途规则另行确认。

## 诺芙
弥珞的同学与重要关系对象；公共术式工程方向，后进入市政结界局。与弥珞是明确恋人关系，但两人保留各自工作与日程；亲密更多进入交通、等待、吃饭、旅行、梳头、洗碗、下班等普通场景，而非只存在于专门约会章节。她常帮助弥珞区分“我能做”“别人需要我做”“我只是很想看”三者，但不是弥珞的管理者。

## 瑟弥娅
19岁苏醒 → 语言恢复 → 现代居民身份 → 技术史协作 → 获得工资 → 独立购物/交通 → 20岁 → 现代公共技术课程学生 → 历史制度语义顾问。当前优先描述为现代学习者与协作者。第一次外国旅行中继续把古代记忆与现代经验分开：过去会自然被想起，但今天仍然首先属于今天。第225章以较完整的瑟弥娅第一人称书写归国后的普通现代生活：她收到自己从岬灯寄回、晚本人十二天抵达的明信片，并主动将其放进私人抽屉而不是公共档案。她开始拥有“哪些东西只属于我、无需变成历史材料”的清晰边界，同时形成自己的课程、公交、食堂、购物和家庭习惯。

第226章继续瑟弥娅第一人称，并正式推进她与涅芙拉的恋爱。她已经不再把涅芙拉是否每天出现当作自身生活能否成立的条件；正因为能够独立上课、工作、出行和旅行，她才更清楚地分辨出“我仍然会想她”是个人喜欢而非单纯依赖。她主动说出“我喜欢你”，并选择“恋人”作为两人的现代关系称呼。后续仍保留自己的房间、课程、工作、钱与私人抽屉，不因恋爱重新退回被照料者身份。

第227—228章进一步推进她面对“古代身份重新闯入现代生活”的能力。月川镇两支现代家系可能与她二姐姐一系存在历史联系，但现有证据不足以确认血缘。瑟弥娅能够同时承认私人记忆带来的情感震动和证据边界：她提供“我不是门”等日常记忆，却明确拒绝把相似发扣、家族口述或地方戏直接升级成血缘、继承、政治身份和仪式特权。她也拒绝旅游合作会把自己写成“归亲王女”，并拒绝把涅芙拉套入“翼卫”古代职位。她只决定本人姓名、私人关系和口述材料如何被使用，不替月川现代居民裁决其地方治理争议。

## 涅芙拉
古代梦契种/魅魔，现代铁路与公共安全相关工作人员；曾任高级锚定员。深紫黑色膜翼，长期强调同意与边界：“能到达，不等于应该进入。”她最初作为古代语言与现代生活支持者接近瑟弥娅，能够直接理解部分古语，也成为瑟弥娅刚苏醒时的重要安全感来源。

她并未利用这种依赖发展私人关系，而是有意识等到瑟弥娅的正式语言教学、生活支持和独立行动能力稳定以后，才以私人身份发出“不是课”的邀请。第226章两人在河西旧机务街第一次明确约会；涅芙拉承认自己早已有私人喜欢，在牵手、张翼和接吻等接触前仍逐项询问。两人现为恋人，但涅芙拉继续保留自己的工作与住处，不承担全天候陪伴义务。

第227—228章外部人员第一次试图把她根据膜翼和瑟弥娅古代身份解释成“翼卫”。这一称呼没有历史依据，后来查明主要来自月川九十多年前地方戏《月灯第三女》的“夜翼守者”角色。涅芙拉不接受因此获得任何古代职务或从属身份；她是否陪伴瑟弥娅参与外部事务仍由本人决定。第228章家系会谈结束后，她只以恋人身份下班来接瑟弥娅吃饭，没有进入会谈充当护卫或翻译。

## 弥宁
一年跳跃后16岁；仍在成长，和家庭、学校及新技术接触。她的测绘/地图线已经形成独立于姐姐的知识路径，能够在姐姐不在场时完成学习、形成判断，再在晚上交换各自经历。第215章首次完整切换为弥宁第一人称：在塔温港对同一岸段做低潮、中潮、高潮三轮教学测绘，进一步理解“时间、用途和参照定义”是线成立的一部分。她仍然喜欢抱姐姐、撒娇和分享，但不需要姐姐见证自己的每一次成长。第225章收到塔温港学校寄回的课堂合影与交换反馈，继续把外国经历作为自己的学生成长而不是姐姐旅行的附属。

## 塞缪尔
精灵，皇家自然史学院退休教授，主要研究大型迁徙生物行为与长期山地自然史。第3章在列车事故中首次登场；当时他没有把自己的长寿或教授身份当成天然权威，而只是支持弥珞关于旧“过境式”应先核实的判断。第4—8章与弥珞、芙蕾娅同行，长期保持冷静、重证据、不把地方名/学名/旧分类强行压成唯一正确名称。

第8章明确其重要人物原则：任教后经常把精灵耳尖藏入长发，不是羞于种族，而是因为学生知道他活得很久以后容易把“教授的长期记忆”误当成不可质疑的一手证据。他曾因自己讲错旧猎人记录年代而公开重讲课程；希望年轻研究者先听证据，再纠正他，而不是因年龄与身份自动服从。

第46章他发现北部负林兽会避开鸣晶中继塔部分工作状态，并警告转报网扩展前必须评估对魔法生物导航、繁殖与夜间活动的影响；曾写信说若工业部门以“尚未发现明显伤害”为理由跳过长期观察，会亲自到实验室门口坐着。

第238章他真正履行这句旧话，带数十年迁徙记录和皇家自然史学院的野外静听设备回到灰岭。其新主张不是把所有自然问题变成工程审查，而是让**长期观察本身成为基础设施**。第239章重返最初列车事故所在谷地；年轻研究员珀拉当场纠正他对个体年龄的判断，他直接接受并要求证据，正式回收第8章人物钩子。

塞缪尔当前不承担全天候主线导师功能。他有自己的学院、野外研究、同事与年轻继任者；与弥珞的关系更接近长期互相校正的前辈/同行：他会支持她不被现成系统压掉的问题，也会阻止她把所有新问题立即挂到自己的技术树上。

## 其他
芙蕾娅、雷奥妮、伊莱娅、绯墨、珀拉等人物继续按章节逐项核定。感情线可以继续扩展，但不以强行配对替代人物自身生活。
