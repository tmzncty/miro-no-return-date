# 人物表

## 弥珞
第一人称主角，猫族；擅长地方结界文献、调谐、测绘及在非标准环境中寻找路径。状态：学院学生 → 专业资格即将失效的毕业生 → 旅行者/地方问题记录者 → 技术与社会协作者。不是天选之人，也不是所有技术的发明者。当前20岁；第一次外国旅行中开始真正形成跨国、跨海视野，但“想去更远”不等于立即把远方变成项目。

## 诺芙
弥珞的同学与重要关系对象；公共术式工程方向，后进入市政结界局。与弥珞是明确恋人关系，但两人保留各自工作与日程；亲密更多进入交通、等待、吃饭、旅行等普通场景，而非只存在于专门约会章节。

## 瑟弥娅
19岁苏醒 → 语言恢复 → 现代居民身份 → 技术史协作 → 获得工资 → 独立购物/交通 → 20岁 → 现代公共技术课程学生 → 历史制度语义顾问。当前优先描述为现代学习者与协作者。第一次外国旅行中继续把古代记忆与现代经验分开：过去会自然被想起，但今天仍然首先属于今天。

## 弥宁
一年跳跃后16岁；仍在成长，和家庭、学校及新技术接触。她的测绘/地图线已经形成独立于姐姐的知识路径，能够在姐姐不在场时完成学习、形成判断，再在晚上交换各自经历。第215章首次完整切换为弥宁第一人称：在塔温港对同一岸段做低潮、中潮、高潮三轮教学测绘，进一步理解“时间、用途和参照定义”是线成立的一部分。她仍然喜欢抱姐姐、撒娇和分享，但不需要姐姐见证自己的每一次成长。
