# 网络、交换与远距离传输

本文件汇总此前分散在正文中的网络技术钩子，并以第236—237章为当前成熟状态锚点。

## 基础分层

当前公共网络不把“所有机器联网”理解为一台中央机器控制一切，而是分成若干职责明确的层次：

1. **终端 / 室环**：建筑、车辆或单一设施内部的短距设备互联。采用局部席位、准备—交付—收到—释放的双向确认，不要求统一总钟。
2. **公共交换柜**：把同一地点或局部网络中的多个终端、交换柜和上行口连接起来，负责本地交换、缓存、端口状态、局部席位关系和媒质能力，不解释应用正文。
3. **门房**：网络与真实执行设备之间的权限边界。网络能提交请求，不等于有权直接打开泵、仓门、车辆、医疗设备或其他物理执行层。
4. **区域远驿路由节点**：负责跨区域“下一大段往哪里走”，维护区域级路径、代价、过期与退化状态，不要求每个本地交换设备知道全国地图。
5. **长距干线 / 再生中继**：解决跨数百至上千公里的实际物理传输问题，把长距离拆成多个可维护、可校验、可单独失败和恢复的段。

这套分层延续第49章以后“室环 / 远驿 / 门房”的结构，也吸收第93章远驿第二版的会话租期、静窗与退出确认，以及第105章“灰岭以外机器还没有学会彼此说话”所暴露的跨地区互连问题。

## 第一型公共交换柜

状态：第236章完成量产放行，进入普通产品阶段。

背景：早期远驿节点常使用第四号通用转报计算器同时承担地址、巨帧、路由、拥塞、媒质转换和本地接入。该路线适合早期试验和大型站点，但随着学校、市场、诊所、车站和工坊终端数量增加，在每个局部路口摆一台通用计算器成本过高、功耗和维护也不合理。

第一型公共交换柜把“交换”从通用计算中拆出，主要规格为八口、十六口、三十二口，可通过可更换媒质片接入雾银导脊、铜纹短线、澄脉译接等不同本地媒质。

核心原则：
- 每个端口独立接收、校验与缓存，不要求所有设备同速；
- 保存局部席位与端口关系，但关系具有租期，终端搬动或拔线后旧端口不能继续长期占用身份；
- 支持席位迁移、端口静窗、能力协商和局部拥塞退让；
- 对未知目的或冗余链路的泛送设有余站限制、路径印记和环回疑似检测，出现循环时可暂停未知泛送而保留已知点对点关系；
- 不读取或理解应用正文，不因连接更多设备而偷偷长成小型万能计算机；
- 与门房、区域路由、真实执行控制保持职责分离。

成熟性证据：在正式量产放行前已完成约八个月试用，覆盖学校、诊所、市场、车站、小型工坊、档案馆、居民服务站和区域装配点。地方维修者可更换常用媒质片和维护部件，不要求每次端口故障都由灰岭工程师到场。

叙事意义：第105章提出的“灰岭外机器彼此不说同一种话”没有通过一台全国万能机器解决，而是通过便宜、专用、可维护的局部交换设备逐步变成普通基础设施。

## 再生中继长距干线

状态：第237章完成一千一百多公里级全长业务试验，进入区域试用；尚未构成覆盖全国的统一高容量骨干网。

问题来源：早期长距传输大量依赖鸣晶塔、铁路电报线、雾银、地方转接站和多种人工/自动中继。短文本可以工作，但距离增加后，脉冲展宽、噪声、相位偏差、不同媒质转换和逐段补偿会累计；简单放大可能把误差和噪声一同放大。

再生中继的关键不是“把同一个波形放得更强”，而是每一段完成：

**接收 → 判决 → 校验 → 重新生成干净物理信号 → 交给下一段。**

消息身份与顺序继续，上一段的模拟波形、幅度和噪声不必继续传播。

第一阶段陆地试验利用既有铁路通信廊道，把一千一百多公里线路分为十余个不同长度的维护段。媒质不强求统一：普通区段以改良铜纹双线为主，部分湿地和旧桥段继续使用鸣晶或雾银等既有路径。统一的是再生站行为，而不是全国材料。

### 分段确认，端到端复核

- 每一再生段对相邻段做局部确认；某一块只在第五段损坏时，由相邻站局部重发，不需要发送端重新跨越全部距离。
- 终点仍对完整内容做端到端校验，避免中间节点“各自都说成功”却最终拼出错误内容。
- 允许多个编号块同时处于不同传输段，形成受控**在途窗**；窗口根据最差链路、缓存和拥塞状态增减，而不是每一块都等待全程回执后才发送下一块。

### 退化与备用路径

第237章故障试验中，主动切断一段主干后，区域路由节点转入低容量鸣晶备路：
- 安全短报、普通文字和小状态继续；
- 大型显文图、批量档案等大块传输暂停并保留队列；
- 状态明确写作“低容量备路”，不伪装成完全正常；
- 主干恢复后先经过短序列、校验块和“恢复观察”，再恢复普通大块业务；
- 已经跨过的健康区段不因一处中断而被视作全部失败。

### 运维边界

长距离能力依赖的不只是线路材料和算法，还包括沿线再生站的供能、冬季结冰检查、备件、铁路作业车、湿地鸣晶漂移处理、旧线外护层巡检以及值守人员。叙事上不能把“一千公里网络”写成一根抽象线，而应写成许多可维护地点与人的班次。

## 计划休眠与远端维护

第259章把第165章边远低功率节点“按窗口醒来、其余时间休眠”的运行方式推进到长期支持层。

- 计划休眠 / 静窗是有来源、有时间范围的正常运行安排，不等于未知失联或设备故障。
- 区域远端维护系统可在约定交换窗口读取供能、最近交换、温度、基础自检等状态；窗口外不应仅因没有回应自动生成故障。
- 第一版试行服务档称 **“计划窗口可观察”**：面板显示下一预计观察时间；应有窗口未出现、连续窗口失败或真实维护指标越界才触发异常处理。
- 窗口由实际地方责任方声明；变更必须保留来源与生效时间。厂商 / 服务方不能为了统一监控频率单方面改成持续唤醒。
- **不得仅为满足远端监测频率而唤醒已经进入约定休眠的站点。**
- 该服务档不是“山区低保障”的同义词。医务、消防、道路安全等高连续性业务能否休眠，取决于真实服务后果、其他链路和本地责任判断，不能按地区身份自动决定。

这一规则没有产生新的网络控制权，也不改变门房 / 本地责任边界；它只是要求长期支持层尊重底层已经明确表达的运行语义。

## 与跨海海缆的关系

镜潮湾—赛乌岛第一期跨海低速电报线没有海底主动中继，依靠低速发送、高灵敏接收与岸站补偿完成七百多公里跨海传输。

陆地再生中继成功后，**不能直接推导海底也应照搬**。陆地中继站可进入、可供电、可换模块；海底主动中继一旦故障，定位、回收、密封、供能与维修成本完全不同。未来海底再生属于研究问题，可能出现岸站改进、无源补偿、海底主动中继或岚汀方面的其他路线，但当前不视作既定项目。

## 当前完整网络链

第237章完成一次端到端组合验证：

**终端 → 本地交换柜 → 门房 → 区域远驿路由 → 再生长距干线 → 区域远驿路由 → 本地交换柜 → 终端。**

没有任何一层需要知道全部世界。局部交换柜不需要全国路由，长距再生站不需要知道应用内容，终端也不需要知道沿途第九中继站在哪里。

这是一条重要成熟标志：网络开始能够通过职责分层扩大，而不是靠单台机器承担越来越多知识。

## 后续开放问题

- 区域交换柜的第二版外壳、端口可读性、地方维修培训和非机械社兼容件；
- 更大规模网络中的路由收敛、区域间结算、容量公平与紧急业务优先级；
- 长距干线的多路复用、线路共享、不同业务资费和隐私边界；
- 冬季、雷暴、强魔力背景、铁路廊道中断情况下的长期可靠性；
- 计划静窗、季节性窗口与跨机构长期支持责任如何在更多地方系统中表达，且不被误写成统一“低保障”服务；
- 是否需要专门的高容量全国骨干，以及集中建设与多区域互联之间的制度选择；
- 海底主动中继是否值得、怎样维护；
- 与维尔兰、岚汀等不同国家 / 政治实体互联时，协议共同语法与各自权限 / 监管边界如何同时保留。
