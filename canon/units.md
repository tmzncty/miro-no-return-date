# 计量、时间与编号规范

本文件是《弥珞没有返程日期》的正典编辑规范之一。它规定的是**正文对读者的转写方式**，不要求世界内部所有地区历史上都真实使用完全相同的单位。

## 1. 现代通用计量默认采用公制转写

为避免为了“异世界感”制造一套没有叙事价值、又容易失去比例感的单位，现代日常、工程、铁路、测绘、医疗和公共设施的标准量，默认按读者熟悉的公制表达：

- 长度：毫米、厘米、米、公里；
- 面积/体积：平方米、立方米、升、毫升等，在确有需要时使用；
- 人体身高：米/厘米；
- 工程距离：米/公里；
- 精细零件：毫米/厘米。

已经成文的早期正文也支持这一点：如榆背镇外勤使用“九公里、二十五公里、十二公里、一公里”等距离；体检章节明确使用“160.8”“一米六”“三厘米”等现代长度表达。

这可以理解为叙述者对世界内标准单位的现代中文等值转写，而不是宣称异世界历史上发明过现实世界的 SI 制。

## 2. “码”不是本作的通用长度单位

当前正文没有建立“1码”等于多少米的可靠定义，而且现有“码”出现在完全不同的语法位置：

- `第五码站`、`第七码站`：本应是站序号；
- `四十七码书`：本应是“四十七本书”；
- `二十七码人`：本应是“二十七人”；
- `十八点零七码`、`六时四十七码`：本应是时间数字；
- `八码桌`：本应是“八张桌”；
- `七码高`、`七码半`、`六码左右`：又被当成长度。

这些互相无法由同一个换算关系解释，因此确认：**“数字 + 码”在绝大多数现存位置属于文本生成/编辑污染，不属于世界观正典。**

只有“码头、号码、编码、密码”等汉语本来就包含“码”的词正常保留。

## 3. 长度修订按语境恢复，不做机械替换

不能把所有“七码”简单替成“七米”或“七号”。应根据语法、尺度与既有场景分别恢复：

- 王冠中央饰叶 `七码高` → 应为约 **7厘米高**；
- 港岸水尺 `三点七码` → 应恢复为 **3.7米** 一类读数；
- 木桩外 `七码半` → 可按场景恢复为 **7.5米**；
- 安全边界 `六码左右` → 可按场景恢复为 **6米左右**；
- 教学岸段 `约七码长` 不能直接改成7米，因为同段还出现7.5米水边与6米安全退让，必须重新核定整体尺度，优先改成约几十米级的合理教学岸段。

凡涉及工程尺度而上下文不足的旧句，先列入审校，不凭一个字面数字强行修复。

## 4. 编号与序数

- 第几个站：`第五站、第六站、第七站`；若是设施正式编号可写`五号站`，但同一系统不可混用。
- 线路/车辆/航线正式编号：`七号环线、海门七号`等。
- 码头：可以写`第七码头`、`第八码头`，因为这里的“码”属于“码头”这个词，不是单位。若强调正式编号，也可在统一修订时采用`七号码头/八号码头`，但同一港区应统一命名格式。
- 机构名若以数字编号：用`七号`而不是`七码`，例如`桥下七号仪表社`。

## 5. 数量与量词

不得用“码”代替量词：

- 四十七本书；
- 二十七人 / 二十七个岗位；
- 八张桌；
- 七只烤饼；
- 七个包；
- 一百零七页。

量词可按叙事口语省略，但不能以“码”占位。

## 6. 时间

现代叙事统一写成正常汉语时间：

- `18:07` → `十八点零七分`；
- `6:47` → `六时四十七分`或`六点四十七分`；
- `晚七分钟` → `晚了七分钟`。

`息`可以继续作为文学性的极短时间感受词（如“几息”），但不应和精密钟表读数混成正式换算单位，除非古代史料明确建立该单位。

## 7. 身体感与地方口语

“半指宽、一臂远、几步、走一会儿”等可以保留，用于人物即时估计和感官描写；它们不是工程标准单位。

古代文献、地方行业或外国地区如果未来确实需要出现本地旧单位，可以使用，但必须满足至少一项：

1. 对剧情或地方史有意义；
2. 首次出现给出大致现代换算或通过场景建立尺度；
3. 明确它属于某时代/地区，而不是作者随机换单位。

## 8. 后续写作硬规则

- 新正文禁止把“码”当万能数值后缀。
- 新写数字后必须检查：它表示的是序号、时间、数量还是物理量。
- 工程数字优先写实际单位；不确定尺度时宁可写“几米、几十米、约一段街宽”，不要发明单位。
- 历史单位若没有叙事必要，不为异世界感而造。

该规范自第221章后的新正文立即生效；旧章中的污染另做全库审校与逐句修订。
