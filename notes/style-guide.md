# 文风与叙事约定

## 基础视角

- 默认第一人称，以弥珞的有限认知为主。她可以聪明、会误判、会后来才理解，也可以单纯不知道。
- 特殊章节可以切换人物视角，但必须有明确叙事必要，不用全知视角替人物解释人生。
- 不替弥珞预先命名人生，也不把配角写成等待她触发的支线任务。

## 文学性不是“多断句”

- 段落允许舒展。优先让一个段落承载动作、感官、思绪和关系的连续变化，而不是把每个句子拆成独立段落制造“文学感”。
- 少用无必要的 `---`、空白幕间和口号式断句。章节应当能够连续阅读。
- 长短句服务于呼吸与情绪：紧张时可以收短，观察、回忆、旅行与复杂思考时可以拉长。
- 不在每个场景结束后立刻总结“所以我们明白了什么”。有些意义让物件、动作、沉默、下一次回忆自己完成。

## 场景优先于说明

- 技术、制度、政治、历史首先要成为人物正在经历的东西：声音、温度、气味、重量、距离、排队、手续、身体动作、食物、故障、等待、账单、误解。
- 避免把章节写成技术报告或世界观百科。即使信息量很大，也要有场景推进、人物欲望、阻力、发现和余波。
- 外国、古代、王都、工业区都不是“主题公园”。写当地人怎样上班、回家、吃饭、抱怨、维护、娱乐，再写它的技术奇观。
- 专业知识通过不同人物的兴趣分配：伊莱娅先看维护，雷奥妮先看计算，诺芙先看权利与关系，弥宁先看图与时间，弥珞不必替所有人问完。

## 人物与对白

- 对白要保留人物声音。不要让所有人都说同一种漂亮结论。
- 关系通过动作和边界呈现：谁会先问“可以吗”、谁会直接抱、谁只碰衣料、谁累了会说“抱一下”，这些比关系标签更重要。
- 撒娇、幽默、吃饭、衣服和猫行为不是降低文学性的插曲；它们是人物抵抗宏大叙事吞没自己的方式。
- 允许人物不把感情说完。沉默、转移话题、记住一件小物、以后再次提起，都可以承担潜台词。

## 技术与时代

- 技术是物质文化，也是劳动、制度、资本、身体和地方知识的结晶。不要只写“发明成功”。
- 成熟技术最重要的变化常常是变便宜、变普通、被别人改得更好、被学生嫌慢、被维修工嫌按钮硬。
- 外国技术路线不按“先进 / 落后”二分；不同社会会把资源、历史、能源、组织方式做进机器里。
- 政治可以进入小说，但不能吞掉小说。权力必须落回具体人的时间、选择、工作和代价。

## 计量、时间与编号

- 现代叙事默认按公制转写：毫米、厘米、米、公里等。人体、工程、铁路、测绘与设备尺寸优先使用这一体系。
- **“码”不是本作通用异世界长度单位。** 旧章中数字后异常附着“码”的情况已确认为文本污染，详见 `canon/units.md` 与 `notes/unit-audit.md`。
- `码头、号码、编码、密码`等正常词不受影响；`第七码头/第八码头`里的“码”属于“码头”一词，也不是计量单位。
- 新正文写数字时先判断它属于：序号、时间、数量还是物理量。分别使用“第五站 / 七号线”“十八点零七分”“二十七人 / 四十七本书”“7厘米 / 7.5米”等正常表达。
- 不得把数字后无意义地附加“码”来代替站序、量词、钟表时间、编号或物理单位；每个数字都必须按语义使用正常写法。
- 工程尺度不确定时宁可写“几米、几十米、约一段街宽”，不要为异世界感临时发明单位。
- 地方旧制或古代单位只有在确有叙事意义时才保留，并应在首次出现时用换算或场景建立尺度；不同地区可不同，但必须明确是地方差异，而不是作者随机换单位。
- “半指宽、几步、一臂远”等身体估计可以用于人物感受，不作为正式工程量。

## 可从文学史中调用的手法

这些是叙事工具，不是要求模仿某位具体作家的腔调。

- **地方性书写**：让地理、方言、食物、交通、劳动习惯和地方制度共同塑造人物，而不是只把地方当背景。地方不是“风景介绍”，而是生活为什么会这样发生。
- **现实主义的复杂矛盾**：尽量避免把结构性冲突压成一个坏人。人物可以都说真话、都有限制、都承担代价，矛盾仍然成立。第212章《潮门》是可复用例子。
- **反讽**：少靠作者直接评价，多让制度语言、宣传语、角色期待和实际生活并置。反讽不等于阴阳怪气；它可以来自“完全合法、完全正常，却仍然荒谬”的距离。
- **陌生化**：把熟悉的机器、城市、爱情或权力换一个观察位置，让人物重新看见。比如从蒸汽城普通乘客的擦窗动作理解“一个人的视野装不下一座城”，而不是先讲理论。
- **复调与群像**：同一问题让工人、管理者、学生、维修者、恋人、地方居民各有声音；不让弥珞替所有人总结。配角之间也可以形成关系和争论。
- **都市蒙太奇 / 并置**：车窗、广播、报纸、广告、工地、家庭灯光、路人对白等可以交叉出现，制造“同一时间许多生活同时发生”的城市感，但仍要保持第一人称可感知范围。
- **戏中戏 / 文本中的文本**：戏剧、诗歌、旧书、报纸、档案、放映画面都可成为第二层叙事。它们不是插入论文，而是让人物通过另一段故事重新理解自己正在经历的时代。
- **叙事时间错位**：过去档案、现在舞台、以后回忆可以并置；不要为了技巧而炫技，必须让时间层改变读者对人物或事件的理解。
- **物象承担历史**：票、旧表、发带、工作服袖口、地图折痕、磨损扶手、半张报纸、过期状态牌等小物可以比大段说明更稳定地保存时代变化。
- **留白与未完成**：关系不一定告白完，谈判不一定在主角离开前结束，戏剧也不一定把人物未来交代干净。没有结案本身可以是现实感的一部分。
- **诗性意象**：雾、河、灯、铃、车窗、白汽等可以反复出现，但每次必须在新的关系中改变含义，避免只写漂亮景物。
- **兴与触景生义**：可以从一件具体外物起笔，让意义后来才长出来；不要一开始就宣布主题。盐迹、雾、汽笛、旧桥、窗外第一场雪都可以先作为物存在，随后才与人物处境发生关系。
- **复沓与变奏**：来自《诗经》、歌谣等传统的重复不是复制。一个句子、声音、地名或动作可以多次返回，每次因人物、语境或时间变化而变义。第213章“一长两短”与“第七码头有灯，第八码头有声”分别在档案、顺口溜、酒馆歌和现场听闻中变奏。
- **乐府/口述传统的多声部**：诗歌不只来自书斋和“作者”。工作歌、地方唱词、儿童顺口溜、船员口述、街头改词都可以保存社会经验；不要把民间声音仅作为风俗装饰。
- **志怪式记录与传奇式生长**：面对无法完全解释的事，可以先如志怪笔记那样老实记“何时、何地、谁听见/看见、未知何故”，不急着解谜；随后允许不同讲述者像传奇和民间故事一样增加人物、因果与情感。关键是区分“记录能证明什么”和“故事如何生长”，两者互不替代。
- **赋的铺陈需要方向**：工业港、市场、车站可以有铺陈和列举，但不能只为了炫耀世界观。所列之物必须有流向、用途、阶层或时间关系，让繁盛本身成为社会结构而不是名词堆砌。

## 时间、意象与回返

- 时间跳跃必须留下物质痕迹：衣服尺寸、头发、身高、旧机器、第二版书、磨损的车、习惯改变，而不是只写“大家成长了”。
- 可反复出现的核心意象包括：路、车窗、地图、铃声、回信地址、饭桌、衣服、头发、机器的状态、旧物被重新理解、返程与没有返程。
- 意象重复时要发生变化。同一条路第二次出现，人物已经不是第一次经过的人。
- “没有返程日期”最终不等于不能回家，而是人、国家、技术与时代都不能返回原样。

## 收束原则

- 一章可以解决一个问题，也可以只改变读者理解问题的方式。
- 不追求每章爆点。普通的一顿饭、一次修理、一场游戏、一天没有成果，都可以成为完整章节，只要人物和世界在其中真实地移动。
- 保留余地。世界很大，未知不是空白，也不需要马上填满。
