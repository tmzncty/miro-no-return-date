# 第七百八十六章　那本灰绿色工作本摊在饭桌边，我只看了她指给我的那一页

### 瑟弥娅

涅芙拉开始六周试轮值后的第四天，我第一次看见那本灰绿色工作本。

其实它先出现在饭桌上，我过了好一会儿才意识到那就是她前些天去文具铺买的那一本。

我到她家时已经七点十二分。学院小组今天没有拖堂，只是我们把一块旧型公共站房疏散模型拆回材料箱时，发现两只标号牌贴反了。那不是模型本身的技术问题，却足够让四个人重新把整套零件按清单核一遍。等我从学院后门出来，原本说好的七点已经过去九分钟；再走到车站、换一次线，最后三分钟就落在涅芙拉楼下那段上坡里。

我没有钥匙，所以还是敲门。

门里先传来椅脚轻轻擦过地面的声音，然后是翼收拢时很熟悉的一阵布料和羽缘摩擦。涅芙拉把门打开，只说：“你比消息里早两分钟。”

“我走快了。”

“为什么？”

“因为饿。”

她看了我一眼，让开门口。屋里有煮豆和烤菌菇的味道，厨房那只小锅正在很轻地冒汽。我把肩袋挂到已经习惯的位置，没有往里多走，先问：“鞋放这里？”

“嗯。”

这句话我们其实早就不用每次确认，但门边今天多了一只折起来的训练用软隔带，占了平时鞋尖会靠到的那块地方。我把鞋往左挪了半掌，才没有碰它。

“这个怎么带回家了？”我问。

“不是现场件。”涅芙拉说，“训练区报废的练习带，明天带回去做站位演示。边缘已经起毛，不能再拿去真现场。”

她说完去看锅，我把外套脱下来，才注意到饭桌右边压着一本灰绿色的窄本子。

封面不是我想象中的硬壳，边角也没有包。右下角已经有一点向上翘，大概被她塞进工作袋时压过。一本只用了几天的东西，已经开始像真的工作本，而不是文具店里摆得整整齐齐的新本子。

它没有锁，也没有被她收起来。

我走过去放自己的水杯时，杯底差点碰到本子。我把它往桌子里面推了一点。封面因为桌面不平自己滑开一道缝，里面露出几行黑字。

我伸手把它合上了。

没有看。

涅芙拉端着锅出来，正好看见我的手从本子上移开。

她先把锅放到垫板上，又看了看本子，问：“怎么了？”

“差点洒到。”

“里面没什么不能见人的。”

“那也不是我的本子。”

她没有说“你可以看”。只是把锅盖掀开，热汽一下涌出来，把她脸前几根头发吹得往上翘了一点。

“先吃。”她说。

我很赞成。

她这几天开始试轮值以后，晚饭时间没有突然变得更规律。正式带教只占六周排班的一部分，原岗位没有消失；她依然有站内值班、交接和普通维护协作，只是其中几段班次换成了训练区。第一天她发消息说自己“嘴比手更难停住”，第二天只发了一张很潦草的晚饭照片，第三天我下课时她还在做交接，我们根本没见面。

今天是第四天。我们没有庆祝“第一周快过半”，也没有约好一定要复盘。她只在下午问我有没有空吃饭，我说有，但九点以前得走，因为明早第一节还有材料课。

锅里的豆比我想象中咸。我吃了两口就去拿水，涅芙拉看见，说：“今天盐倒多了。”

“你知道？”

“尝过。”

“那为什么不加水？”

“加了。还是多。”

我笑起来。她把烤菌菇往我这边推了一点，说：“这个没多。”

吃到一半，她才把那本工作本拿过来，放到自己手边。她没有翻，只用指腹在封面上轻轻压了两下。

我问：“今天不顺？”

“没有出事。”

“我没问出事。”

她抬头看我。

我继续吃豆。

过了几秒，她说：“有一个新人一直等我说下一步。”

“你说了吗？”

“前三次说了。第四次忍住。”

“然后呢？”

“她站了二十多秒。”

“很久？”

“在训练区里很久。真的现场不一定。”

涅芙拉说，她今天带的是一段受控交接练习。新人要从状态牌、维护记录和现场位置里确认一扇模拟门究竟处在“已隔离待检”“可复核但不可复位”还是“记录与现物不一致，应先停下”中的哪一种。设计者故意留下两条互相冲突的信息，不是要考人猜中答案，而是看她什么时候愿意承认自己不能继续往下。

“她前面三次一停，我就问‘下一步看哪里’。”涅芙拉用筷子在桌边点了一下，“她后来就开始等我问。”

“所以第四次你不问。”

“嗯。”

“她最后自己停了？”

“先想往下做。手抬起来以后又收回去，自己说记录和牌不一致。”

我点点头：“那不是很好？”

“很好。”

“你听起来不像觉得很好。”

涅芙拉低头把最后一块菌菇夹走，说：“因为她后来问我，‘是不是我只要等得够久，你就会告诉我？’”

我忍不住笑了一声。

她看我：“很好笑？”

“有一点。”

“我当时没笑。”

“你当然不能当着她笑。”我把碗往前推了一点，“那你怎么答？”

“我说，我前三次确实告诉得太快，所以她这样想有道理。然后重做了一遍。”

“这不是答得很好吗？”

“岑遥也说可以。”

“那你还皱眉做什么？”

涅芙拉没有马上回答。她把空碗叠起来，起身送去水槽。右翼从桌边经过时差点碰到那本工作本，她很自然地用左手先把本子挪开，像已经做过很多次。

“因为明天轮到我做开班说明。”她背对我说，“不是一对一练习，是一组。”

我听懂了。

她以前很会说明事情。

或者说，她很会在事情必须立刻被人听懂的时候说明。铁路站台、紧急交接、陌生人靠近危险边界、四百年前有人在她面前听不懂现代话——她都不太缺声音。

可带教的开场不是下命令。

涅芙拉把碗泡进水里，关掉水龙头，回头问我：“你能不能帮我听一遍？”

我先看那本工作本，又看她。

“听哪一段？”

她这才把本子翻开。

不是第一页。

她翻到中间靠前的一张，把本子转向我，用手指压住上半页，指着下面用铅笔写的一小段。

“这一段。”

我只看她指的地方。

上面是她准备明天说的开场。字比她平时工作记录圆一点，大概因为写的时候不是站着。第一句很普通：欢迎、训练范围、哪些地方是模拟件、哪些动作今天不能做。第二句开始谈“不确定”。

她写：

**遇到不能确认的状态，不要猜。先停下，把你已经确认的事实说清楚，再决定需要查记录、问人还是退出当前动作。**

我读了一遍，又读第二遍。

“怎么样？”她问。

“你想让我听什么？”

“像不像在骂人。”

我抬头。

她很认真。

我再低头看那句话。

“第一遍不觉得。第二遍有一点。”

“哪里？”

“‘不要猜’。”

“本来就不能猜。”

“我知道。”

“那为什么像骂人？”

我想了一会儿，说：“因为如果我是刚来的，我可能会先想，我刚才是不是已经猜过了。”

“那不是坏事。”

“也不是好事。你开场第一句话还没说完，人先开始回忆自己是不是已经做错。”

涅芙拉把本子转回去，在“不要猜”下面点了一个很小的点。

她没有立刻改。

“那换成‘不确定可以先停’？”她问。

“你问我没用。”

“刚才不是你说像骂人？”

“我只能告诉你我听起来是什么感觉。”我说，“你明天面对的又不是我。”

她看了我一会儿，点头：“对。”

然后她在旁边写：**明天先问岑遥 / 看新人反应，不因一人意见定稿。**

我觉得这很像她。

也很像她这四天正在学的东西：别人说了一句，不等于她必须立刻把整套做法改成那一句的样子。

她把本子往回收了一点，又问：“还有一个。”

“你今天请我吃饭到底是不是为了找免费听众？”

“不是。”

“那为什么有两个？”

“因为第二个我本来不确定要不要问。”

我靠到椅背上：“你问。”

她沉默了一会儿，视线没有落在本子上。

“你刚醒的时候，”她说，“我是不是也经常太快告诉你下一步？”

我的手停在水杯上。

厨房里水槽还泡着碗。窗外有车从小街另一头过去，轮胎压过一小片积水，声音从楼下拖到很远。屋里没有别的动静。

我没有马上回答。

这不是一个完全陌生的问题。

第779章吃酸汤饼时，我自己问过她，她以前教我古语的时候是不是也会站得太近。她说会，我说那时候有一阵我确实需要她站近一点，后来就不需要那么多了。

可“你是不是太快告诉我下一步”不太一样。

它一下把我带回了比古语课更早的地方。

刚苏醒的时候，很多现代词我根本听不懂。门为什么会自己合上，水为什么从墙里来，纸上的日期为什么和我记忆里的任何纪年都对不上，别人进房间以前为什么先按一个会响的小片，为什么有人只看我一眼就知道我“是那个醒来的王女”。那一段时间里，我每天都在被别人告诉下一步：先坐，先喝水，先别出去，先学这个词，先签这一格，先等检查结果。

涅芙拉当然不是唯一一个告诉我的人。

她甚至常常是最愿意等我自己开口的那个。

可她是我最能听懂的人。

这让她说的每一句“先这样”都比别人的更重。

我把水杯放下。

“你是想把我那时候的情况拿去做带教例子吗？”我问。

涅芙拉的翼很轻地收紧了一下。

“没有。”她说，“我只是想知道我以前怎么做过。”

“为什么？”

“因为我最近才发现，自己觉得是在帮人省一步的时候，对方可能会学会等我。”

她说得很慢。

“我不是要把你写进训练本，也不会跟新人讲你的事。”

我点头。

我相信她。

可我还是没有立刻回答原来的问题。

我伸手把那本灰绿色工作本往她那边推回去一点。不是推开，是让它不再正对着我。

“那一段我不太想拿来帮你练带教。”我说。

涅芙拉看着我。

“好。”

就一个字。

没有问为什么，也没有补一句“我只是随口问”。

我反而继续说了下去。

“不是因为不能讲。”我说，“是因为我刚才一听你问，就先回到那间房里了。我现在不想为了你的试轮值再把那段翻一遍。”

“好。”

“你别连续说两次好，听起来像站务确认。”

她嘴角动了一下。

“那我说知道了？”

“更像。”

这次我们两个都笑了。

笑完以后，屋里刚才那点突然绷紧的东西没有消失得像从没发生过，只是松开了一点。

我低头看自己的手。指尖上还有今天拆模型时沾到的一点灰，洗过一次仍在甲缝里。

“你可以问我现在当学生的事。”我说。

涅芙拉没有立刻拿笔。

“你确定？”

“现在的可以。你问具体一点。”

她想了想：“有人站在你旁边等你做的时候，会不会让你更快？”

“会。”

“更快就是更好吗？”

“有时候更快，有时候只是不敢停。”

她这次才拿起笔。

我告诉她，去年有一次基础装调课，老师并没有催我，只是一直站在我右后方看。我本来想停下来重新核一遍连接方向，可因为他已经在那里看了十几秒，我忽然觉得再停就是“还不会”，于是直接往下做。最后没有出事故，也没有装错到需要返工，只是我做完才发现自己其实少看了一条记录。

“老师后来知道吗？”涅芙拉问。

“知道。我自己说的。”

“他怎么处理？”

“下一轮他去看别人了。”

“就这样？”

“就这样。”

涅芙拉把笔停住。

我说：“所以你也别把这个写成‘站远一点就解决’。有时候人不在旁边，我也会自己急。”

“我知道。”

“第几次？”

她愣了一下，才反应过来我在学伊莱娅那章里祁槐数“我知道”的玩笑——其实我当然不知道她有没有听过那个故事，只是她今天已经说了好几次。

涅芙拉看着我：“第三次。”

“你还真的数？”

“刚开始数。”

我笑得差点把水碰翻。

她伸手扶了一下杯子，却没有替我把它拿远。等我自己把杯子往里挪，她才重新低头。

这一页最后只多了两行：

**站位影响停下的空间，但不是唯一原因。**

**开场只说明“可以停、如何说清已知”，不要替新人预演所有正确反应。**

她写完以后问：“还听吗？”

我说：“你刚才不是只让我听一段？”

她看了看本子。

“对。”

然后把它合上。

我们开始洗碗。

她洗，我擦。不是因为这是我们固定分工，只是她已经把手泡进水里了。我擦到第二只碗时，发现碗沿有一点豆皮粘着，又递回去。涅芙拉接过去重新冲，没有说“刚才明明洗过”。窗边那条抹布今天晒得不够干，摸起来还有一点凉，我把擦好的碗放到架上，没有立刻收进柜子。

洗到最后，她问：“你刚才合本子的时候，真的一眼都没看？”

“看见字了。”

“什么字？”

“没读。”

“为什么？”

我把勺子擦干：“因为你没有叫我看。”

“如果我一直不叫呢？”

“那我就一直不知道里面写什么。”

她把水关了。

我以为她会接着问“你不好奇吗”。

她没有。

她只是把手上的水甩掉，拿毛巾擦干，然后重新走回桌边，把工作本翻到第一页。

“这一页可以看。”她说。

我走过去。

第一页最上面是日期。下面原来写过四个字，已经被划掉，仍然能辨出来：**带教要点**。

旁边改成了：**我需要学的事。**

再往下是第一场准备训练后写的三条：手比嘴快；知道下一步，不等于替别人把下一步指出来；翼也算站位。

第四条的位置有一行被划得很重。墨色还透得出来一点，但我没有努力去辨。

我抬头看她。

涅芙拉自己把那一行指给我：“那天回家写了‘重要的结果可以先告诉她，不等于她必须立刻来’，后来划掉了。”

“为什么划？”

“因为不是带教记录。”

我看着那条被划掉的字。

“现在怎么又给我看？”

“因为你刚才说，我没叫你看，你就不会看。”她说，“我想让你知道这一条写过。”

“可你还是划掉了。”

“嗯。”

我没有说它该不该留。

那是她的本子。

我只用手指碰了一下纸页最下面还空着的地方。纸很薄，背面已经透出下一页一点铅笔痕。四十八页大概真的会够六周，也可能不够；如果不够，她可以再买一本。没有哪一种结果需要现在决定。

“第一页看完了。”我说。

涅芙拉把本子合上。

“谢谢。”

“谢什么？”

“帮我听。”

“我只听了一段。”

“就是那一段。”

八点四十，我开始穿外套。

时间没有因为我们谈了过去就变慢。明早的材料课仍然是第一节，我那张还没画完的连接剖面也不会因为恋人正在学带教而自己完成。涅芙拉明天比我更早出门，她要先回训练区，把那条起毛的软隔带带回去，再参加开班前的准备。

她没有问我要不要留下。

我也没有解释为什么今天不留下。

今天本来就只是吃饭。

门口那只软隔带还在原来的位置。我穿鞋时差点踩到边缘，涅芙拉弯腰把它提起来，往墙边挪了一点。

“明天你会把开场改成什么？”我问。

“还没定。”

“我刚才说的那句呢？”

“只是一个意见。”

“很好。”

她看我：“你这是考我？”

“没有。我就是很满意。”

“那不一样吗？”

“当然不一样。”

她送我到楼下。

夜里有一点风，路边树叶还没完全落完，车灯经过时会照出一层薄薄的灰。走到站口，她没有继续送进去，因为她明早也要早起。我在闸口前回头，她还站在外面，右翼被风吹得松开一点，又重新收住。

我挥了挥手。

她也挥了一下。

车上还有座位。我坐到靠窗的位置，从肩袋里拿出自己的课程本。今天那张连接剖面剩下右下角一段，我本来想回家再画，后来觉得车还要坐二十分钟，干脆先把尺寸关系核一遍。

列车转过西环弯道时，纸页在膝上轻轻滑了一下。我用手压住。

我的本子里没有涅芙拉明天要说的开场，也没有她前三天带过的新人。她的本子里也不会出现我今晚这张还没画完的剖面。

窗外一站一站往后退。

我低头把下一条线画了出来。
