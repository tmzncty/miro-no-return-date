# 第七百四十二章　跑道边的草还没动，二百米上那层风先把第二张试验卡留了下来

我从东部平原回来以后，一直没去过灰岭公共低空验证场。

这件事在我骑车拐进南郊那条旧路时才突然变得很明显。路边的仓库没有搬，验证场外墙也还是那种很难让人产生“航空时代”联想的灰白色，只是以前总靠墙停成一排的三轮运输车少了两辆，自行车棚却往外接长了一截。入口旁边那块春季外缘观察图已经换过版，最下面多了一行很小的字，提醒今天南侧有屋顶排水检修，九点半到十一点之间会有高处人员活动。

我把车锁好，抬头第一眼还是去找风向袋。

它垂着。

不是完全不动。尾端偶尔会轻轻翻一下，像一条刚睡醒、不太想替任何人工作的布尾巴。跑道边昨晚结的露还没有干，短草一根一根压着水珠，太阳从东边低仓库的屋脊后面出来以后，最先把靠近硬地那一条照亮。

如果只看这里，今天是一个很适合让猫产生乐观判断的早晨。

然后我看见北侧气象坪上已经升起了一只系留探测器。

白色小囊不大，从地面看只比手掌大一点，细线在几十米以上几乎看不清。真正奇怪的是它的线。靠近地面的一段很直，往上却慢慢偏向另一边，到更高处又拉出一道更明显的弧。

我站在登记窗前，耳朵已经转过去了。

值班员把夹板递给我：“先签。”

“上面风不一样？”

“先签。”

“今天不是九点才做第一轮剖面吗？”

“改到八点十分了。”

“为什么？”

他用笔尖点了一下我面前那张来访登记表。

我只好先把姓名、单位、访问范围和离场预计时间填完。

今天我不是来参与飞行决定的。联合机械社地面安全组每隔一段时间会来做一次接口复核，这次轮到旧式地面状态板、试验卡和气象附件之间的记录关系。我在东部平原轮驻以前就被排进了名单，只是日期后来往后挪过两次，最后正好落到今天。

所以我有正式理由进场。

这很好。

当然，就算没有，我也会想来看。

值班员收回夹板，终于说：“昨晚外海背景更新得比原计划早。赛乌那边先报了压降和风向变化，镜潮湾今早六点多把沿岸判断往前修了一点。本场气象组决定把第一轮高度剖面提前。”

“锋面已经到灰岭了？”

“没有。”

“那——”

“你进去问气象员。”

他大概已经不想替里面的人回答第二遍。

我背好包往北侧值班楼走。走到机库前时，那架我已经见过很多次的双座样机刚被牵出来。

它没有变成我离开四个月以后忽然出现的下一代飞机。

机头还是那个机头，翼面上几处颜色略有差异的修补也还在。以前左下侧那块让我每次都忍不住多看两眼的补漆已经旧得和周围差不多，反而是右轮支柱附近新换的一小段防泥护片颜色更深。两名机务正蹲在下面擦昨天下午留下的细泥，一名飞行员站在翼根旁边看试验卡，手里还拿着没吃完的半块面包。

没人围着它拍照。

也没人宣布今天要创造什么纪录。

我顿时更高兴了一点。

值班楼里比外面暖。窗玻璃上有一层很薄的水汽，桌上摊着三份天气材料和两张浅黄色试验卡。最上面那份来自本场，下面压着镜潮湾沿岸气象中心的区域摘要，再下面才是赛乌北岸的外海观测转报。

顺序和我脑子里第一眼想看的顺序完全相反。

我先把手缩回来。

本场气象员正对着一卷刚回收的记录纸看数值，听见我进门，只说：“你来得正好。先别看飞机。”

“我已经看了。”

“那现在看风。”

他把第一轮剖面推给我。

地面到一百多米都很普通。风不大，方向也没有突然变化。再往上，记录开始慢慢偏开：大约一百七十米以后，风向出现转动，二百米附近的速度也明显增大；再往上一点，变化没有继续整齐扩大，反而开始抖得更厉害。

“这是锋面？”我问。

“这是八点十分到八点二十六分，本场上空这一条剖面。”

“我知道，我是问——”

“你刚回来第一天就想把它命名？”

我闭嘴。

他笑了一下，才把镜潮湾那张区域摘要翻出来。

赛乌的外海观测比灰岭早几个小时看到气压变化和低层风向转动。镜潮湾沿岸几个站随后也开始出现相似趋势，但锋面位置、推进速度和进入内陆以后低层结构会怎么变，仍然有不确定。灰岭昨夜收到的只是区域背景，不是“你们二百米高度几点会吹什么风”。

“所以你们提前放探测器。”我说。

“对。”

“然后真的在二百米附近看到了变化。”

“对。”

我耳朵已经竖得很高。

“所以赛乌——”

“没有看见灰岭二百米的风。”他把铅笔横着放到记录纸上，“赛乌只是让我们今天早点问一次：上面现在是什么样。”

这句话让我安静了几秒。

窗外那只白色探测囊正在被慢慢收回来。靠近地面以后，牵引线的弧度越来越小，最后重新变成一根普通的细线。

桌上两张浅黄色试验卡这时才轮到我看。

第一张是低高度操纵复核，范围没有超出这架样机已经重复做过的低速离地和短程控制边界。第二张则包括更高一层的爬升与侧风响应记录，原本计划在第一张完成后继续。

两张卡不是“第一阶段成功以后自动解锁第二阶段”。

它们各有自己的前置条件。

第二张右上角已经被气象员用铅笔写了一行：

**待第二轮本地剖面；当前不满足直接进入准备。**

我问：“那第一张呢？”

“还没决定。”

“地面风不是很好吗？”

“所以地面风很好。”

“低层一百多米也没超——”

“所以一百多米这一轮观测没超。”

我看着他。

他也看着我。

“我知道了。”

“你知道什么？”

“你不替负责人签字。”

“很好。”

我怀疑这里的人经过这么多年，已经很擅长用最少的话阻止我把几个箭头接得太快。

九点前，第二轮探测器升了起来。

这次我跟着气象组去了外面。

草地上的露已经干了一半，鞋底踩过去还是会留下深一点的痕。操作员把线轮放在低架上，一只手控制放线，另一只手不时摸一下制动。探测囊越升越小，最初还能看见白色，后来只剩天空里一个几乎认不出来的点。

我以前在东部平原也见过很多系留观测。

林地那边为了看雾、近地温度和局部低扰魔力背景，设备有时只升几十米；更高的气象观测则由专业人员做，林业组不会因为手里刚好有一根线就把自己变成气象站。那四个月教会我的一件事是，同一种动作——放线、收线、记时间——可以服务完全不同的问题，真正区分工作的不是动作有多像，而是谁知道自己在测什么、为什么测、测完以后能说到哪里。

我站在旁边没有碰线轮。

第二轮结果和第一轮相似，却不完全一样。

变化层往上挪了一点，最明显的风向转动没有落在刚才同一个高度，速度也不是简单重复。气象员看完以后没有说“验证成功”，只在两张记录之间画了一个很短的括号，标出它们共同支持的范围：今天上午较高低空确实存在一个需要单独对待的变化层，但它在移动，具体结构不能用一条固定水平线画死。

验证负责人这时才从机库过来。

飞行员也来了，面包已经吃完，手里换成自己的检查夹。

四个人站在一张很普通的折叠桌旁边讨论了十分钟。

我没有被排除，也没有被要求发表意见。

这其实很舒服。

气象员先讲本地剖面，不讲赛乌故事；场务讲跑道和外缘状态；机务说样机上午检查正常；飞行员则把第一张试验卡从头到尾重新看了一遍，问了两次低高度范围和返回条件。

第二张卡很快就被留在桌上。

不是撕掉。

不是取消整个项目。

也不是因为“天气不好”三个字被盖上红章。

验证负责人只在上面写：

**本轮不执行。高层条件不满足本卡前置；另择窗口。**

飞行员问：“低段？”

气象员说：“气象侧当前没有提出停止低段的条件。后续若近地变化，重新评估。”

场务说南侧屋顶检修的人已经按计划进场，但位置不进入今天低段范围；外缘观察组也确认公共穿越带当前清楚。

机务最后说：“飞机没意见。”

所有人都看他。

他补了一句：“我是说检查没意见。”

我没忍住笑。

十点过后，那架双座样机才真正被牵到跑道头。

我已经很久没在这么近的地方看它离地。

第一次的时候，所有人的身体都会跟着机器一起紧。轮子离开地面几十厘米都足够让人屏住呼吸，谁也不知道下一秒会不会出现一个以前没见过的问题。现在不一样了。地面组依旧认真，检查项也没有因为“飞过很多次”变少，可那种全场把一次离地当历史事件的气氛已经没有了。

验证负责人甚至在最后确认前喝完了自己那杯快凉的茶。

动力声升起来时，跑道边的草终于开始被气流压低。

样机向前滑，速度一点点起来。轮子离地以后没有猛地往上冲，只沿今天第一张卡规定的低高度段爬升，保持在已经验证过的范围里。它从我正前方过去时，翼面在太阳下亮了一下，随后向左做了一个很缓的转弯。

我抬头一直看。

它当然没有去二百米那一层。

这件事用眼睛其实看不出来。天空没有画着一条线告诉我“这里以上今天不做”，飞机也不会飞到某个高度突然撞上一堵透明墙。真正存在的是地面那张没被执行的第二试验卡、本地两轮剖面、飞行员已经确认过的范围，以及所有人都愿意在今天只做其中一段。

不到十分钟，样机重新落地。

没有掌声。

机务先过去看轮胎和支柱，飞行员下机以后把自己的记录夹交给数据席，然后站在翼下活动了一下肩膀。验证负责人没有问“感觉怎么样”，先问的是卡内几个具体动作有没有按计划完成。飞行员逐项回答，最后说：“低段没有出现需要提前终止的情况。不能拿来推第二张。”

“本来也不能。”气象员说。

“我知道，我替你省得一会儿写。”

“你省不了，我还是要写。”

两个人显然已经这样说过很多次。

我跟着数据席回值班楼时，真正轮到今天和我有关的工作才开始。

问题很小。

两轮高度剖面到底应该放在哪里。

旧流程里，本地气象观测有自己的编号和保存位置。某一次飞行或地面验证如果用到它，就在试验卡附件里引用。可最近天气链变长以后，外海背景、沿岸解释、本地加密观测和具体试验之间的关系越来越密。有人为了查阅方便，提议把“为某次试验临时加做”的剖面直接复制进对应试验包；另一些人反对，因为同一份观测可能同时服务当天几个不同任务，复制三份以后，半年后很容易出现一份补过说明、另外两份还停在旧版本的情况。

数据席的人把三只文件夹摊开。

“你们机械社那边总喜欢接口。”她说，“来，接口来了。”

“我没有总喜欢。”

她抬头看我。

“好吧，我喜欢。”

第一只文件夹是气象记录，第二只是第一张已执行试验卡，第三只是第二张未执行卡。

我最初也觉得，把今天两轮剖面复制进两个试验包最直观。

直到我看见第三只文件夹上那行“本轮不执行”。

如果以后有人只按试验结果查，第二张卡会是一个很干净的“未执行”；可今天那两轮较高低空观测并没有因为第二张卡没飞就不存在。反过来，如果观测只被塞进第二张卡附件，它又会看起来像一份失败试验的附属物，而不是本场自己的天气记录。

我想起东部平原那些林地观测。

一张湿度表可能最初是为了道路倒木风险加密的，后来又被林业组拿去看幼树补充；一个观察盒可能因为某次公共节点复核临时多开半小时，可那半小时仍然首先是一段有地点、有时间、有设备状态的环境记录。它可以被很多问题引用，不应该为了最初是谁出钱、谁提出问题，就从此只属于那个问题。

“气象原记录留自己的位置。”我说。

数据席的人点头：“继续。”

“两个试验包都只引用编号、有效时间和本次实际使用范围，不复制成自己的原件。第一张写它用于低段判断，第二张写它导致本轮前置条件不满足，但第二张没有执行，不把观测结果改叫‘试验结果’。”

“沿岸摘要呢？”

“也是引用，不复制？”

“为什么是问号？”

“因为它不是我的专业记录。”

她笑了。

气象员从后面走过来，把一张空杯子放到水池边：“沿岸摘要本来就有自己的版本号。引用版本和接收时间就行。赛乌原始转报也不要再抄一遍，不然明年有人会以为我们这里保存的是赛乌站的权威副本。”

“那很好。”我说。

“什么很好？”

“每一层都不用搬家。”

数据席的人把铅笔在桌上滚了一圈：“你们两个说得都轻松，最后是我要改模板。”

“只改今天？”我问。

“先改今天。下一轮开会再决定要不要变成固定格式。别因为三只文件夹终于说得通，就给我发明全国标准。”

“我没有。”

“你耳朵有。”

我把耳朵压低了一点。

最后我们只在今天的工作模板里加了三项引用：来源记录编号、使用时间范围、用途说明。没有新系统上线，没有任何东西自动从赛乌流进飞机控制器，也没有谁因为跨海电报快了，就把七百多公里以外的风直接写进灰岭跑道状态。

中午十二点，我和他们一起去验证场小食堂吃饭。

今天是炖豆、煎蛋和一碗很淡的菜汤。飞行员坐我对面，吃到一半时我还是忍不住问：“第二张下午真的不再看了吗？”

“看天气当然会继续看。”她说，“试验不追。”

“如果下午突然特别好呢？”

“那也不代表人员、飞机状态、外缘条件和准备时间都还在原来的窗口里。”

“所以另约？”

“另约。”

她夹走最后一块煎蛋，又补了一句：“我下午三点还有体能复核。我不打算为了等一层风自己消失，把午饭以后的人生都留在跑道边。”

我觉得这句话很合理。

于是我也没有继续等。

下午一点多，地面安全组把今天接口复核该看的东西看完，我签了离场。走出大门时风向袋终于撑起来了一点，朝东北方向斜着。远处第二只探测囊已经收走，天空看起来仍然和平时一样，没有人能从蓝色里直接看见那层上午移动过的风。

我骑车回城，经过南郊那排低仓库时，忽然想起很久以前自己在一本私人笔记里写过一串特别兴奋的箭头。

回家以后我真的把那本找了出来。

纸已经比当时软一点，边角也有翻得太多留下的毛。那一页很容易找到，因为我当年写得特别大：

**海线 → 外海实测 → 沿岸预报 → 低空验证？**

最后那个问号几乎占了两行。

诺芙正在厨房洗一只锅，听见我翻纸，问：“今天飞了吗？”

“飞了。”

“那你为什么从进门开始一直说二百米上的风？”

“因为第二张没飞。”

她把锅放到沥水架上，擦了擦手：“所以你今天最高兴的是没飞的那一张？”

我想了一下。

“也不是。”

“那是什么？”

我低头看那串旧箭头。

当年我写它的时候，箭头很直。每一个技术像只要被前一个点亮，就会自然地往下一个地方流。现在那几样东西确实已经发生关系了，却没有哪一根线真的这么直：赛乌看自己的海，镜潮湾做自己的判断，灰岭把背景拿来决定要不要更早问一遍本地天空；本地观测再进入当天的责任判断，而飞机只飞自己今天被允许飞的那一小段。

我没有把原来的箭头擦掉。

只在“沿岸预报”和“低空验证”中间，挤着加了两个很小的框。

一个写：**本地观测。**

另一个写：**本轮条件。**

位置太窄，字有点歪，把原来那根箭头切成了三截。

那个很大的问号还在。

厨房里水壶开始响。诺芙叫我去拿杯子，我把本子合上，先去喝水。
