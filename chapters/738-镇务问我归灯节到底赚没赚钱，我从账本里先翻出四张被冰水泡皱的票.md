# 第七百三十八章　镇务问我归灯节到底赚没赚钱，我从账本里先翻出四张被冰水泡皱的票

### 芮禾

入秋以后，月川的鱼比夏天安静一点。

不是说河里没有动静。清晨第一批活鱼送到市场时，木槽里的水还是会被尾巴拍出一层薄亮，几条小河鲈照旧喜欢挤在进水口下面，鼻端一下一下顶着水流。只是天冷了，人站在槽边久一点，手背先知道季节往前走了。水汽没那么厚，铁夹摸上去发凉，案板冲过两遍以后也干得快。

我那天刚把第三条鱼的鳞刮完，市场管理员就拿着一沓纸从东口进来。

她没穿归灯节那种浅灰临时背心，只套了件旧夹衣，袖口夹着一支铅笔。走到我摊前时，她先避开地上的水，再把最上面一张纸递过来。

“商户补充反馈。”

我没接。

手上全是鱼鳞。

“放那边。”我用下巴指了指秤旁边干一点的位置。

她把纸压在空竹筐下面，免得风吹走：“不是今天就要。下周三以前。”

“上次不是填过了吗？”

“上次是活动后一周的现场反馈。这次是全年经营复核，镇务和旅游合作会要分开看。”

“分开什么？”

“节庆当天你觉得顺不顺，和过几个月以后回头算账，到底有没有赚到、付了什么额外成本，不一定是一回事。”

这句话听着很像他们已经被谁骂过一轮。

我问：“谁提的？”

她说：“很多人。”

然后补了一句：“你们市场尤其多。”

这就不奇怪了。

她继续往西边发纸。澄姨隔着两摊喊：“有没有‘别再让我写字’这一格？”

管理员头也没回：“没有。”

“那你们调查不完整。”

“你可以写在意见栏。”

“意见栏才最累。”

我把手上那条鱼处理完，冲了刀，才去看那张表。

第一栏很简单。

**与普通同季星期相比，归灯节相关时段营业收入：明显增加 / 小幅增加 / 基本持平 / 减少 / 无法比较。**

第二栏复杂一点。

**额外成本：临时用工、延长营业、冰/燃料/耗材、交通与送货调整、临时设备、废弃与损耗、其他。**

后面还有两块，一块问活动交通安排对经营有什么影响，一块问下一年度若继续举行归灯节，市场时段是否愿意延长。

我先把纸翻过去看背面。

背面没藏什么东西，只有一行说明：这份表只用于商户经营与市场运行复核，不代替承灯参与者、志愿人员、居民或游客反馈，也不作为对历史家系问题的意见调查。

我看完以后，把纸重新压回竹筐下面。

澄姨从旁边伸头：“怎么，不会填？”

“会。”

“那你什么表情？”

“我要找账本。”

“赚没赚钱你自己不知道？”

“知道一点。”

“那还找什么？”

我指了指她摊后那排咸菜坛：“你知道归灯节那天卖得比平时多，能不能马上说多出来的钱减掉你提前两天多腌的菜、那天多用的炭、晚收摊一小时，还有你侄女来帮你看摊的工钱，最后净多多少？”

澄姨想了一下。

“不知道。”

“所以。”

“但我可以猜。”

“你猜你的。”

“你这个人卖鱼卖得越来越像账房。”

我没有理她。

中午客少的时候，我把后屋那本厚账翻出来。

账本不是专门为了归灯节留的。里面什么都有：每天进货多少，饭馆预订多少，哪一批鱼到得晚，哪只木槽换过塞子，冰行哪天少送半箱，雨太大时市场几点提前收。归灯节那一页反而很普通，只是字比平时密，边角还有一片很浅的水渍。

我翻了两遍，先找到当天的收入记数。

确实比同季普通星期高。

不是高得吓人。看灯的人上午不怎么买整鱼，这件事那天我已经知道；真正多出来的是下午旅店和几家饭馆的追加单，还有活动结束后回家的人顺手买的小鱼。炸鱼、热饼、甜卷那几家肯定比我涨得厉害，我这里只能算多卖了一些。

再往下看，额外成本也在。

多补了一次冰。

因为下午车流切换，冰行原定那趟比平时晚到十二分钟。十二分钟本身不算什么灾难，冰也没有坏，但为了撑到晚间收摊，我还是让他们多留了一箱。那箱冰到最后没有全用完，第二天还能接着用，可账上依旧是归灯节那天付的钱。

延长营业以后多用了两桶清水，照明多开一段时间，收摊也比平时晚。最外面的几条小鱼到了晚上已经不适合继续按活鱼卖，我便降价给了桥北两家做汤的店。没有扔，损耗不算大，可原本能按另一种价格卖出去的可能，也没有办法当作从未存在。

我在账页中间找到四张折得乱七八糟的小票。

其中三张是冰行的，一张是清洁耗材。纸角都被水泡过，字还看得清。归灯节那晚收摊时我把它们连同零钱一起塞进围裙袋，第二天才发现纸和湿布贴在一起。后来我摊平晾干，夹进账本，想着哪天再算。

哪天就是今天。

我拿铅笔在旁边算了很久。

收入是多的。

净下来的也还是多一点。

但如果只看市场后来贴出来的“节庆日总营业额较普通周末明显增加”，我会以为自己那天赚得比实际更多。

因为总数没有告诉别人，卖热食的人可以把人流直接变成一只一只拿走的饼，整鱼摊却得先想着客人愿不愿意拎着一袋会滴水的东西逛桥；总数也不会写冰行车在北口多等了十二分钟，不会写有人为了晚收摊把第二天上午的进货量减了，也不会写哪一家看起来卖得多，其实只是把第二天会卖的东西提前卖掉。

我把四张票排在桌上，看了一会儿。

门外有人叫我。

我出去以后，面包铺的小姑娘正站在鱼槽前。

她今天没扎归灯节那晚那根浅色布带，头发只是随便用一根深蓝绳子束住。围裙上有两块面粉印，一只手里拎着面包铺装零钱的小布袋。

“有小河鲈吗？”

“有。”

“今天不用留两条。”

“你买几条？”

“一条。我妈说晚上煮粥，放两片鱼肉就行。”

我从槽里挑了一条大小合适的，放上秤。她看见竹筐下面压着的反馈表，问：“你们也发了？”

“面包铺也有？”

“早上发了两张。一张店主填，一张当日额外用工自己填。”

“你填哪张？”

“第二张。”

我把鱼装进湿纸袋：“写什么？”

“实际多干了多少？”她接过袋子，“还能写什么。”

“你那天不是少干了一小时吗？”

她看我一眼：“你是不是只记得我可能上桥那一小时？”

我停了一下。

她笑了：“前后都忙。替班的人来了以后我确实少扛了一部分，可活动结束那批客人回来时我又在。最后收炉比普通星期晚。”

“那你是多干还是少干？”

“所以我也得算。”

她把零钱放到我手里，没走，反而靠在摊边看了一会儿水槽。

我问：“现在还有人叫你八号吗？”

她脸上的笑淡了一点，不是生气，像听见一个已经有点烦、但也懒得每次都发火的词。

“有。”

“很多？”

“没刚结束那几天多。熟人主要是拿来逗我。外地人偶尔会有人认出来，那天公共远景里我有一小段在面包铺门口喝水，后来不知道哪家小报写‘第一候补在工作中等待’。”

“听着挺烦。”

“是有点。”她用手指戳了戳鱼袋上折起的纸角，“我后来跟店里说，明年要是我没报名，宣传别再写‘候补面包铺’。面包铺本来就有名字。”

“他们答应了？”

“本来就不是店里写的。旅游合作会那边说以后如果要用这种说法会先问。反正今年节后我们自己的黑板早擦掉了。”

她停了一会儿，又说：“不过那一个小时的重叠班倒没完全丢。”

我抬头。

“什么意思？”

“我妈后来试了几次。不是每个星期都加人，太贵。现在碰上面粉车和下午大炉一起到的那两天，会提前让桥北阿姨来半个小时。归灯节那天本来是为了候补，后来发现有些时候单纯是两个人做比较顺。”

“那你们算归灯节的成果？”

她想了一会儿，摇头。

“算归灯节逼我们试过一次。能不能留，是另一回事。”

我觉得这句话可以抄到市场的表上。

但不是我的店。

我把自己的笔记本合起来：“你鱼拿好。”

“知道。”

她走出两步，又回头问：“你支持明年继续吗？”

“归灯节？”

“这个市场时段。”

“还没填。”

“你居然还会没意见。”

“我有意见。太多，所以还没写。”

她笑了一声，拎着鱼回面包铺。

下午两点以后，秋日的太阳斜进市场棚里，水槽边缘亮得发白。来买菜的人比上午多，游客少了很多。归灯节已经过去很久，桥南临时步行线的胶痕都快被日常车轮和雨水磨干净了。偶尔还有人站在市场口问“承灯桥往哪边走”，但更多人问的是豆腐、鱼、腌菜和去车站最近的路。

管理员发完那沓表又回来了一趟。

她不是来催我，只是通知晚上收摊后市场公用桌旁会有人解释填表口径，谁不想听可以不去。

“解释什么？”我问。

“有人问‘额外成本’算不算自己多干的时间，有人问当日用掉、第二天还能继续用的冰怎么算，还有人问游客把普通客人挤走算收入减少还是交通影响。”

“你们怎么答？”

“按实际写。自营摊主自己的额外工作时长可以写，但不要硬给自己编一个不存在的工钱；可跨日继续用的耗材不要全算损耗，说明数量就行；普通客流变化如果没有准确数，可以写观察，不要假装有。”

“挺麻烦。”

“所以才是补充反馈。”

她说完准备走，我叫住她。

“你们最后是想知道归灯节值不值得办吗？”

管理员看了我一会儿。

“镇里当然要知道。但不是靠你这张纸一个人回答。”

“那总营业额为什么放首页？”

“因为总营业额确实有用。”她说，“镇务要知道公共交通、清洁、临时厕所、桥面值守和市场延时花出去的钱，整体有没有带来人流和经营活动；旅游合作会要知道宣传是不是把人带来了。可你们又不是一个摊。总数大，不等于每家都划算。上次就有人说我们把‘市场整体上涨’写得太像‘所有商户获益’。”

“所以这次补问？”

“所以补问。”

她没有把前一版说成错误，也没有说这次一定就完整。

“明年会不会继续？”我问。

“承灯办法，镇里另有复核。市场怎么开、开多久，也不是一件事。可能继续活动但调整市场时段，也可能市场时段不变，先改送货线。现在没定。”

“那我写送货线。”

“你本来就该写。”

管理员走了。

傍晚收摊以后，市场公用桌旁最后坐了七八个人。

没有正式开会。管理员搬了一壶热水，谁自己带杯子谁喝。卖热饼的先说她支持明年继续延长，因为归灯节那天晚上比平时多卖了快三成，临时加的两个人工也值；卖干货的老许却说他那天反而少卖，熟客嫌人多，旅游客看得多买得少，第二天才恢复。澄姨说自己挣钱是挣了，但下午送坛子的车在北口排太久，如果明年还这么走，她宁愿早点把货送进来，不要让她为了“节庆氛围”少摆两只菜坛。

“谁让你少摆？”管理员问。

“游客绕不过去。”

“那是动线问题，不是规定你少摆。”

“所以我现在告诉你。”

“那就写。”

旁边有人笑。

我也笑了一下。

这种话在市场里讲，比会议室里好听。不是因为这里更真诚，而是每句话旁边都有东西：谁的篮子占路，谁的摊需要水，谁的炉子必须离人群远一点，哪一辆送货车晚十分钟会麻烦，哪一辆晚半小时也没关系。大家都很难把自己说成整个市场。

卖热饼的说：“游客就是多，这点总没错吧？”

老许说：“多，不等于都买你以外的东西。”

“那也不能因为你卖干货少一点，就说活动没用。”

“我什么时候说没用？”

“你刚才那个语气。”

“我的语气不进统计。”

澄姨立刻说：“那太好了。”

大家又笑。

管理员用铅笔敲了两下纸：“我只解释一个。‘支持下一年度市场延时’不等于‘支持或反对归灯节’，也不等于‘支持哪种承灯办法’。你们可以支持活动，但不想延长自己的摊位；也可以不关心仪式，单独要求送货窗。别为了怕被算成反对节庆，就勉强勾一个经营选项。”

我低头看自己的表。

原来我卡住的就是这里。

我当然知道归灯节会给市场带来生意。就算我的整鱼没有热饼卖得快，饭馆和旅店也会因为人多来加单。镇里办活动要花钱，商户也愿意赚钱，这没什么不好意思。可如果有人问我“所以明年还要不要把市场开到那个时间”，我第一反应不是灯，也不是承灯人，而是北口那辆冰车。

这并不高尚。

也不低俗。

鱼需要冰。

我把“收入”那栏勾在小幅增加，在额外成本后面写了冰、照明、清洁和延长营业。临时用工没勾，因为我没有另外请人；自己的时间写在旁边：**比普通同季星期晚收约一段时间，具体时长按当日账本。** 我没编一个精确到分钟的数字，因为那天中间什么时候算“开始晚收”其实说不清。

交通影响那一栏，我写：

**下午冷链送货经北口，节庆当日实际有短时排队。未造成损坏，但对鲜货经营较敏感。若下一年继续相近时段，请在第一版公开市场运行图中直接标出冷链/鲜货可进入窗口，不要只在最终版补。若时段变化，请尽早通知供应方与摊户。**

市场延时那栏，我没有勾“全部摊位统一延长”。

我在“其他”后面写：

**建议允许按品类与经营者自行决定是否延长，不把提前收摊解释为不配合活动。整鱼、热食、干货的客流时间不同。**

写完以后，我觉得已经够多了。

管理员从旁边经过，扫了一眼：“你没填最后一个。”

我看见最底下还有一行。

**若归灯节下一年度继续以本地自愿报名、公开抽选等方式组织第一段承灯，你作为商户是否认为该方式对经营有明显正/负影响？**

后面有：明显正面 / 轻微正面 / 无明显影响 / 轻微负面 / 明显负面 / 无法判断。

我想了想，勾了无法判断。

管理员说：“为什么？”

“去年大家知道正选姓什么，今年也知道编号。买鱼的人没因为抽签多买一条。”

“也可能有人因为制度变化来参观。”

“那你问游客。”

“问了。”

“那就别让我替他们回答。”

她点了一下头，没有劝我改。

公用桌散得很快。没人宣布“市场形成一致意见”。卖热饼的收起杯子时还在和老许争到底外地人买不买干货，澄姨把自己的表折了三次，差点塞进围裙口袋带回家，最后被管理员叫住才放进收集盒。

我没有当场交。

不是还想改内容，是账本在后屋。我准备把四张冰票的实际金额再核一遍，免得把一箱第二天继续用的冰全算成当天损耗。

回到摊后，我重新翻开那一页。

四张票还排在那里。

账本最里面却掉出一小片硬纸。

我一开始没认出来。纸已经卷边，正面只剩两个字和一个逗号一样的小点：

**二，小。**

我看了几秒才想起来。

归灯节那天，给面包铺小姑娘留两条小河鲈的纸牌。

那晚她最终没有上桥。第一候补没有成为承灯人，一个小时的替班工钱照付，两条鱼也照样被她带走。后来我清木槽时，大概顺手把纸片塞进账本，想着别让湿纸粘住台面。

结果它在这里躺了这么久。

我没有忽然觉得它是什么值得保存的节庆遗物。

鱼摊每天都有这种纸。

“三，大。”

“一，不杀。”

“饭馆，六，午后拿。”

写完、夹上、鱼被拿走，纸就没用了。

我把那张小牌翻过来。背面还算干净。

第二天早上冰行要来，我怕忘记改秋季进货量，便在背面写：

**冰三箱，北口。**

写完以后，我把它重新夹到明天那一页。

反馈表则压在账本下面，等第二天纸边完全平了再交。

收摊时天已经黑了。桥那边没有归灯节的成排纸灯，只有日常路灯落在河面上，风一吹就碎成很短的亮纹。市场里最后一家热食摊还在擦炉边，面包铺已经关了一半门，里面有人把第二天的面粉袋挪到架上。

我推着空鱼箱走到北口，看见地面上原来贴节庆送货箭头的位置只剩一块颜色稍浅的石板。

那天冰行的车就在这里多等了十二分钟。

十二分钟没有毁掉任何鱼，也没有证明归灯节安排失败。可如果下一年还办，我希望有人在最早那张图上记得，这里除了游客、灯和桥，还有下午要进来的冰。

我也会继续卖鱼。

至于到底赚不赚钱，明年还得再算。
