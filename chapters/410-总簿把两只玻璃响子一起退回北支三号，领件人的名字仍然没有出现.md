# 第四百一十章　总簿把两只玻璃响子一起退回北支三号，领件人的名字仍然没有出现

那张“北支三号代转”的副单进了认证站目录以后，我有十多天没有再去看它。

不是因为我忽然不想知道了。

恰恰相反，我想知道得厉害。四十八年前，一只透明玻璃响子和一片中石从北支三号被送出去，经手人写下它大约的口径、高度和那一小段磨平的底缘，又要求照着旧件的口和声音粗配一只，伤处不仿，最后“原件、新件同袋返”。如果那张单真和我手里的铃有关，那么一只铃会在纸面上分成两只；而只要没有客户联、取件簿、工坊承作联或能把某一件实物钉住的连续记录，我就连自己今天拿着的是旧的还是后来配的都不知道。

这种不知道很容易让人上瘾。地图上少一段路，我总想把它接起来；器物中间断一段履历，也会让我反复想象那只袋子后来究竟去了哪里。

所以我故意没去催。

北门公共认证站和地方商业档案馆都在整理那批旧收送资料。它们不是为了我的铃才存在，也没有义务因为我每天都很想知道，就把别的纸先压在下面。素敏上次已经说过，如果同批材料里真的再出现能推进的东西，她会按正常目录关系标出来。

第十一天中午，我去灰岭中央邮局开自己的信箱，里面除了两份地图交换目录和一张旧书铺的价格单，还多了一张很薄的米黄色通知卡。

卡片是认证站寄的，抬头仍然很无聊：

**北路联合收送资料关联检索补充通知。**

下面只有三行手写字：

**同批账簿中新整理出一册返件总簿。**

**有一条记录与“北支三号 / 玻璃响子 / 中石 / 比配返”高度相容。**

**当前仍不改变个人铃来源字段。预约后可查工作复制。**

我在信箱前把三行字看了四遍。

后面有人等着开相邻的箱子，我才发现自己挡住了门，赶紧把卡片和目录一起夹进臂弯里。走出邮局时太阳正照在台阶上，前几天的春雨已经只剩石缝里一点深色，街边卖麦饼的人把铁板支得很靠外，油和葱的味道顺着风一直飘到路口。

我本来已经吃过午饭，还是买了半张。

因为今天下午还有工作。

也因为那本总簿不会在我咬完这半张麦饼以前消失。

我到机械社以后把通知卡放进个人笔记本，没有塞进项目文件。下午先看完一组南片区更新件的状态字段，又和乔葵确认了一台翻新显文端的维修履历有没有把客户名称误带进下一任可见层。五点四十七，我关掉桌上的灯，才给认证站回了预约。

素敏给我的时间是第二天上午十点。

她最后又加了一句：

**不用带铃。**

我回：

**知道。**

过了两秒，又补：

**这次真的知道。**


第二天北门旧仪器街很亮。

雨后的天一旦放晴，旧铺面那些被水洗过的木招牌会显得比平时颜色深，窗玻璃却全是灰。顾氏精仪修理原来的门已经长期不开，花槽里的新叶长到竹支架外面；认证站侧门有人推着一车退役量规进去，车轮压过门槛时，金属盒子在木板上碰出一阵很短的轻响。

我在登记台签了私人查阅，洗手，进整理室。素敏没给我任何“有大发现”的表情。她正在和栖澄把一册厚得几乎合不拢的旧账簿从托架上翻到中间，纸页边缘起毛，书脊新加了保护带。桌上还有一张已经做好的工作复制，原件不用我凑得太近。

“先说什么？”我把椅子拉开。

素敏头也没抬：“先说不是客户联。”

“我就知道。”

“也不是领件簿。”

“继续。”

“没有名字。”

我坐下。

她这才笑了一下：“很好，今天省了我三句。”

总簿比那张副单晚九天。不是说这九天就一定是那次比配所需的完整时间，只能说日期顺序合理。页顶按半月分栏，左边记发出，右边记返入和代转结算；大部分内容一点也不神秘：灯罩六、药瓶十二、裂罐退换、窗片补运、铜夹少一、器材行代收。许多货名后面只有数量和去向，连尺寸都不记。

北支三号那一行夹在“木柄四束”和“药瓶八码箱”之间。

我先看见“北支三号”，再往右看。

**比配返。玻璃响子二，原一、配一。中石一。原袋复封。代转返，自取。**

最末的费用栏盖了一个很小的“结”字戳。

我没有马上说话。

纸上的两只玻璃响子没有颜色，没有口径，没有那段七毫米左右的平磨，也没有任何一句话说明其中一只是从某个具体家庭来的。可“原一、配一”和“中石一”排在同一行里，还是让我后颈那一小片毛不受控制地竖了一下。

栖澄把上次那张副单的工作复制放到旁边。她没有把两张纸叠在一起，只隔了几厘米：“同一半月，北支三号。副单写旧透明玻璃响子一、中石一，要求另配一只，原件新件同袋返。九天后总簿出现北支三号‘玻璃响子二，原一、配一，中石一，比配返’。目前保留下来的这一册里，同一结算期北支三号没有第二条同类返件。”

“所以是同一单？”

她摇头。

我耳朵跟着往下压了一点。

“可以写‘高度相容，极可能对应’。”她说，“不能写成连续单件链。你上次那张是仓内副单，不带唯一工单号；这本是返件结算总簿，也不回抄副单页码。两批档案本身又不是完整保存。我们没看见第二条，不等于当时绝对没有第二条。”

“但至少能说明这种袋子真的有返到北支三号的记录。”

“能说明同一时期有一只包含原响子、配响子和中石的比配返件被记作退回北支三号。”素敏把我的“这种袋子”拆得更慢，“把它与上次副单对应起来，把握很高；把这条总簿直接绑到你今天挂在家的那只铃上，还是不行。”

我点头。

这和我刚看见通知卡时想象的差不多，可真正看见“原一、配一”写在旧账上，感觉仍然不一样。上次那张纸只是告诉我们，经手人打算让两只铃一起回来。现在另一册账簿至少让“回来”不再完全停留在委托句里——有一笔返件进入了北支三号的代转结算。

然后线又断了。

“自取后面呢？”我问。

栖澄把总簿往下一页翻。没有。

再下一页，也没有。

“北支三号自己的领件册不在这批移交里。”她说，“目前也没有别的目录指向它。可能没保存，可能还在另一个没整理的来源里，也可能当年就只留短期柜台记录。我们现在只能说没找到，不能替它写死亡证明。”

“有没有‘逾期未取退回’？”

“这条没有。”

“那能不能证明有人取走？”

“也不能。”

我靠回椅背。

素敏说：“你这个表情很像有人把桥修到河中央，然后告诉你另一半没有预算。”

“至少桥多了一半。”

“对。”

“而且另一半不是不存在，只是现在没有。”

“这句话你可以对地图说，不要对档案说。”

我看她。

她把铅笔放下：“档案会真的被你说出一座不存在的桥。”

我只好闭嘴。


我们又看了那一页很久。

不是一直看北支三号那一行。总簿真正有意思的地方，反而在它周围。北支三号的玻璃响子上面是药瓶和木柄，下面是一批退回重磨的薄铜片，再往后两页，西支二号也有一条“小响具比配返”，数量不是两只，而是三只，随件写的是“参照片一”。另一条更早的记录甚至只写“门挂玻璃补一，旧件同返”，没有标准石，也没有任何专业用途说明。

“所以这种事并不稀奇。”我说。

“至少这种商业操作不稀奇。”栖澄纠正，“小玻璃件、旧件比配、参照物一起送、原件一起退，都是普通服务能力。具体每只东西干什么，还是看自己的记录。”

我盯着西支二号那一行看了一会儿。

如果北支三号那两只铃真的与老妇人家有关，我很容易因为自己现在拿着其中一个候选，就把这一单从整本账里挑出来，写得像它当年也是最特别的那一件。可在总簿上，它只占一行。前后都是别人要用的东西：药瓶要装东西，窗片要挡风，木柄要装回工具，一只旧响具要照样配，配好以后跟原件一起回去。

没有谁在“玻璃响子二”旁边画星号。

当年的仓管大概也不知道四十八年后会有一只猫把鼻子快贴到工作复制上。

我往后缩了一点。

素敏说：“谢谢。”

“我没贴到。”

“你已经快了。”

“工作复制又不是原件。”

“所以我只说谢谢。”

中午前，认证站给这条关联加了一句新的目录备注。不是我写的，最后签字也不是我。

**与北支三号候选副单在时期、代转点、返件构成和业务类型上高度相容；支持同类返件曾退回该代转点。缺唯一工单标识、客户联、领件记录及连续器物链，不进入个人铃来源字段。**

我看完以后问：“‘支持同类返件曾退回该代转点’是不是太绕？”

栖澄说：“不绕就容易变成‘你的铃回到北支三号’。”

“那还是绕吧。”

“很好。”

我没有申请复制整本总簿。真正和我私人研究有关的只有目录卡、那一行工作抄录和来源定位；其余几十页属于别人的旧商业记录，没有必要因为我对一只铃感兴趣就全带走。离开前，素敏问我还要不要把上次那张四十六年前的收送路线图拿来再核一遍。

“我家里那张？”

“你的原件不用。认证站有你同意留的去身份工作复制。”

“那就看复制。”

路线图上的北支三号仍旧只是一个代转点。它覆盖的山地区域很大，线从干路分出去以后还接着几个自然村、林业住点、旧维护站和沿路收送户。总簿新增加的，只是一个返向箭头可以有理由画到这个点上。

点以后没有线。

我拿透明片比了一会儿，最后只在自己的笔记上画了一个很短的箭头，旁边写：

**候选返件 → 北支三号代转。终点仅到此。**

“你居然没往村子方向多画一毫米。”素敏说。

“我会长大的。”

“你二十岁。”

“所以正在长。”

她没理我。


我回家的时候，诺芙已经在厨房切青葱。

门一开，葱味先出来，接着是锅里煮豆子的热气。那只玻璃铃挂在客厅靠窗的木钩上，上午没有风，透明铃身只接住一点斜光，看起来和十多天前、和那张副单出现以前都没有区别。

我换鞋，把包放下，先去厨房从她刚切好的葱里偷了一小撮。

诺芙用刀背敲了一下我的手指：“洗手。”

“我在认证站洗过。”

“你从北门走回家以后没有碰门？”

我去洗手。

等我回来，她才问：“纸又多了一张？”

“不是一张，是一本。”

“你背回来了？”

“怎么可能。”

“那就还是一张。”

我想反驳，发现她说的是我实际带回家的东西，只好把目录抄录从笔记本里抽出来放在餐桌边。她没有马上看，先把豆汤调小火，又把切好的青葱分一半撒进去。

吃饭时我把总簿那一行讲给她听。讲到“玻璃响子二，原一、配一，中石一”时，她夹菜的动作停了一下：“所以袋子真的回来了？”

“有一条高度相容的返件记录回到北支三号。”

她抬眼看我。

“你现在说话很像栖澄。”

“因为‘袋子真的回来了’还是比证据多一点。”

“好。”她低头继续吃，“那纸把两只铃送回代转点了。”

“差不多。”

“然后人没有名字。”

“连有没有被人最终领走都不能确认。”

诺芙点点头，没有替我失望，也没有说“已经很接近了”。她喝了两口汤，忽然问：“如果以后真找到领件记录，而且真能证明是那一家，你会再写信吗？”

我知道她问的不是邮费。

“不会因为找到一张新纸就自动再写。”我说，“她们之前已经说过愿意说的，也说过不希望上门追旧门框。新的档案能改变我对器物链的判断，不能替她们改同意。”

“那如果是她们先寄来东西？”

“再看她们寄来的是什么、同意怎么用。”

“嗯。”

她把最后一块煎豆饼夹到我碗里。

我吃了一半，又抬头看客厅里的铃。

“其实还有一个很讨厌的问题。”

“只有一个？”

“这次说一个。”

“你说。”

“就算领件人真的是那一家，也还是有两只。”

诺芙顺着我的视线看过去：“原的和配的。”

“副单写了伤处不仿，所以新配那只当时大概率没有同样的平磨。可四十八年太久了。后来谁磕过，谁修过，谁换过线，我们都不知道。现在我这只磨过底缘，不能直接把它叫原件。”

“那你更想它是哪一只？”

我张了张嘴。

本来答案应该很快。旧件听起来更接近“最初”，更像一条值得追的路；新配件则像复制出来的旁支。可我想到总簿里那句“原一、配一”，又想到两只铃如果真的一起回到某个代转点，那么从那以后，它们都各自有了四十八年的时间。新的那只也会被挂起、落灰、磕碰、换绳，可能被谁嫌太响移进屋里，也可能被当普通门挂用到没人记得为什么。

“我想知道是哪一只。”我最后说，“但我现在没那么确定哪一个答案比较好。”

诺芙说：“那很好。”

“哪里好？”

“你终于有一个不知道怎么排序的问题。”

“我一直有很多。”

“你通常会先偷偷排。”

我没有承认。

她也没有逼我。

饭后我把碗端去水槽。窗外正好有一辆送菜的小车从巷口经过，右轮压到去年修过的一段石缝，先是很轻的一下木轴声，接着橱柜里两个叠着的碗碰了一声。

客厅的玻璃铃也响了一下。

我和诺芙同时抬头。

车轮又响了两次，越来越远。铃没有再动。

诺芙手里还拿着擦桌子的布：“要不要报修？”

我看她。

她忍着笑。

“先看普通原因。”我说。

“哦。”

“你明明知道。”

“我只是复核住户报知流程。”

“你不是维护人员。”

“那你也不是。”

我把洗好的碗放回架子，水顺着指尖滴了两下。桌上的目录抄录被我压进笔记本，透明路线层夹在后面，那个返向箭头只到北支三号为止。

客厅里，铃还是挂在原来的木钩上。

窗外那辆车已经拐出巷子，街声重新散开。没有第二声。
