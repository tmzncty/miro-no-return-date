# 第三百七十四章　那五百七十米备用缆谁也没借走，账上却第一次多了一栏“不能先答应”

### 塞娅

我第一次看见“可共享备用长度”这六个字，是在星期一早上七点零八分。

那时我刚把湿外套挂到值班室后门，袖口还在往地上滴水。赛乌从凌晨开始下斜雨，雨不大，风却把它一直往窗缝里送，北港那边的吊臂在灰白天色里只剩几道深线。夜班交接已经写完，镜潮湾方向的跨海主线状态正常，外海气象摘要六点四十七分完成一轮，普通付费电文窗口也没有积出值得单独报告的队列。我本来以为今天最麻烦的事会是自己的鞋——左脚那只工作靴昨天开始从鞋舌边缘进水，我下班后还得赶在修鞋铺关门前把它送过去。

槿禾把一张区域海线长期支持协作表放到我桌上时，我甚至先拿它垫了茶杯。

“别垫。”她说。

“为什么？”

“下午要回。”

我把杯子拿起来，看见表格右下角已经有一圈浅浅的水印，只好拿袖子擦桌子。表不是镜潮湾—赛乌这一条线自己出的，也不是哪一国临时发来的命令。第二年深水敷修船共享响应合同生效以后，负责船舶协调、保险和几条区域海线长期支持的协作席，把各线路原来分散的材料状态重新做成一张预案表，想知道在两条线路同时出事、或者某一处备用料不足时，哪些库存“理论上可协助调拨”。

前面的问题都很正常：在役线路类型、深水段结构、岸站接续能力、已有合格材料、最近一次库存复核日期、预计补货周期。直到最后三栏：

**本线已确认深水备用长度。**

**本线最低保留长度。**

**当前可共享备用长度。**

槿禾用铅笔点着第一栏：“五百七十。”

我点头。

这数字我认识得太熟。建设期留下的那卷深水型备用缆，物理总长六百一十二米；外端四十二米有运输固定留下的护甲压痕，后来汇总表一度把总长和当前可直接用于深水永久修复的长度混在一起。我们做过完整盘点以后，只把其余五百七十米算入已确认直接可用余量。那四十二米没有扔，仍在材料复核记录里，只是没有资格为了让库存数字好看就重新加回来。

槿禾又点第二栏。

空着。

再点第三栏。

也空着。

“协作席昨天问，能不能先填五百七十。”她说。

我抬头：“第三栏？”

“对。”

“谁说的？”

“不是命令。只是他们觉得第一栏既然是五百七十，第三栏如果也填五百七十，预案比较好算。”

“那第二栏呢？”

“所以我来找你。”

我低头重新看那三格。纸本身没有做错什么，它只是把三个问题摆得太整齐，以至于人很容易相信三个答案也应该同样整齐。仓库里确实有五百七十米已经确认可用于我们这条线深水段永久修复的备用缆，但“我们有多少”和“我们能先答应借出多少”之间，隔着一整条七百多公里海底线路，以及一件至今还没有真正发生过的事。

我问：“最低保留长度以前是谁定的？”

槿禾说：“没人定过一个固定数字。”

“那就不能填。”

“我知道。”

“你知道还问我？”

“因为我想听你也说一遍，下午就不用只有材料组当坏人。”

这理由很充分。

八点以后，恩澄也被叫了过来。他负责线路测量，看见表格以后先把第一栏划了个框，又在第二栏旁边写了一个很小的问号。他比我们更不喜欢“最低保留长度”这种看起来像只差一次计算就能得出的数字，因为真正的深水故障如果发生，岸测只能先给出带误差的候选区段；船把缆提起来以后，还要切回两端可靠材料，实际替换长度会受损伤范围、海床、水深、抓取位置、为接续保留的操作余量和最终布放松弛一起影响。

“最短的故障不一定只用最短的线。”他说。

槿禾问：“那最多呢？”

“你要我今天给七百公里线路的单次最大永久修复长度？”

“我只是替表格问。”

“那你告诉表格，不知道。”

我说：“很好，下午你自己说。”

恩澄看了我一眼：“你们刚才是不是也这么互相推过？”

没有人回答。

上午九点半，我们把这件事从值班室挪到二号仓库。不是因为看着实物就能自动得到答案，而是槿禾坚持任何讨论“可共享”的人至少应该先看一眼被共享的东西到底有多大、多重、怎么保存。那卷备用缆还在最里面的低温存放区，防潮罩已经换过一版，盘座下方多了排水检查口。外端那四十二米仍有独立状态牌，五百七十米已确认段则有最近一次湿度、端封、护甲与抽样检查记录。

协作席从赛乌本地来了两个人，一位负责保险协调，一位负责共享船合同。他们没有带着“必须借”的态度，反而一进仓库就先问能不能跨黄线。槿禾说不能，他们就站在线外看。保险协调员叫妥仪，她看那只缆盘半天，说：“我在账上一直以为五百七十米就是一行数字。”

槿禾说：“在仓库里它比较占地方。”

“我现在看出来了。”

“而且很难搬。”

“这个合同里也写了。”

“合同不会喘。”

妥仪笑了一下。

她解释那张表为什么出现。共享敷修船不是只为我们这一条跨海线服务，专业接续人员、部分海上工具和某些通用材料也本来就在多条线路之间调度。过去大家只写“各线自备关键缆材”，遇到演练时再逐项问。保险方希望提前知道，如果某条线自己的备用料临时处于复核、运输延迟或修复需要超出原估计，有没有可能从别处获得临时材料支持。她说得很谨慎，反复用了“可能”“候选”“不代表已经承诺”。

“那表格为什么只有一个‘当前可共享备用长度’？”我问。

她低头看表。

“因为最初做表的人想让调度席能直接加总。”

“加总以后呢？”

“比如三条相容线路分别有两百、三百、五百米——”

槿禾在旁边说：“先停。什么叫相容？”

于是上午剩下的一半就没有再讨论五百七十米。

我们开始讨论“相容”。

这一条跨海线第一期的深水缆结构已经固定，导体尺寸、绝缘体系、外护、钢丝层、允许弯曲、接续工艺都有自己的资料。其他线路即使也叫“深水低速电报缆”，也不等于从仓库里剪一段出来就能接。协作席带来的是几条可能纳入长期支持互助的线路公开结构摘要，没有客户业务内容，也没有不必要的部署细节。材料组拿它们和我们的备用缆逐项对照，很快就把“相容”拆成了四种完全不同的东西：能不能在电气上工作，能不能用现有接续工艺可靠封装，能不能承受目标水深与海床条件，能不能由实际被调来的船舶和工具安全处理。

其中一条线路的导体与绝缘参数接近得足以继续研究，但外护甲结构不同，现有船上夹持和过轮条件不能直接照搬；另一条机械尺寸很像，电气参数却会让整段线路补偿重新计算，临时修复也许能做，永久修复不能在没有重新验证前写成“同类替换”；还有一条连用途都不同，只因为库存表里同样写了“深水通信缆”，就被最初汇总的人放进了同一个颜色。

恩澄把三张摘要摆在桌上，问妥仪：“现在加总多少？”

“零？”她试探着说。

槿禾摇头：“也不能写零。零听起来像明确不相容。”

我说：“写‘未建立预先调拨资格’。”

共享船合同那位负责人叫陵渡，他一直没怎么说话，此时终于抬头：“太长。”

“那是你的问题。”

“公众状态可以长，调度表真的不能每格一整句话。”

“那就改表。”

“你说得像改表不要钱。”

“借错一段海缆更贵。”

这句话终于让他闭嘴了大概十秒。

中午食堂有鱼汤、烤海豆和一盘切得非常厚的腌瓜。我们四个人端着盘子坐到靠墙一桌，谁都没有把上午的纸带来。妥仪吃到一半还在想“可共享长度”该怎么改，槿禾让她先咽下去。窗外的雨已经停了，港池上方却还压着低云，几个学生从海务学校那边沿着廊道跑过去，书包外面套着防水罩。广播说下午两点以后北线岛间客船按正常班表运行，东侧一个低频小港仍在等靠泊复核。跨海电报线也仍然正常，没有因为我们讨论备用线就配合着坏一次。

我很感谢它。

吃完饭以后，我去公众说明室借了一块旧教学缆样。不是为了拿它做材料证据，只是下午协作会里有人没有接触过海缆结构，槿禾不想让大家对着投影上的几根同心圆讨论。说明室值班员把样缆交给我时问：“今天又要讲哪一层？”

“讲为什么仓库里有东西不等于别人已经能用。”

“那你可以把坏回位簧也带走。”

“那个已经讲过了。”

“东西修好以后就没人记得它。”

“这是好事。”

她想了想，点头。

下午的会没有开成我原来担心的样子。没有哪一家机构站起来说“互助精神要求你们把库存拿出来”，也没有人反过来说“本线资产一米不借”。真正难的是，大家都认同共享可能有价值，于是才不得不把共享以前那些很扫兴的条件写清楚。

镜潮湾方面通过既有工作通信发来自己的意见。他们那边首先反对把“可共享”理解成长期锁定给别人：如果一段材料提前算进区域公共余量，本线采购和保险很可能在下一次复核时反过来把它从自己的保障需求里扣掉，最后出现同一卷缆在两张表里都被当成“别人可以给我”的情况。海线局的人把这种情况写得很难听，叫**重复依赖**。

我很喜欢这个词，因为它听起来就像会真的害人。

岚汀这边则补了一条更生活的问题：补货时间。五百七十米不是矿脉，也不是今天借出去明天从地里长回来。若真的调给别线做永久修复，我们这边下一卷相容缆材要重新生产、验收、运输、入库，再恢复自己的深水备用能力。天气和船期还会进入运输时间。因而“今天物理上可以剪下一百米”与“今天制度上适合先答应未来一定能剪一百米”仍不是一回事。

妥仪最后把原表格投到墙上，拿铅笔一栏一栏改。她没有删除“共享”，只是把一个数字拆成了几个状态：

**已确认本线可用余量。**

**本线最低保留：固定值 / 情景值 / 尚未建立。**

**跨线技术相容：已验证 / 需工程复核 / 不相容 / 未评估。**

**当前预先承诺调拨：有 / 无。**

**发生实际请求时是否允许重新评估：是 / 否 / 依授权。**

陵渡看了一会儿，说：“这已经不是一张能直接加总的表了。”

妥仪说：“对。”

“调度席会骂我。”

“那你告诉他们，我们今天的成果就是不能先加。”

槿禾在旁边补充：“至少不能把不同意思的米数先加。”

我们的五百七十最后留在第一栏。

最低保留没有被强行填成五百七十，也没有为了表现合作精神随便减出一百。它被标成“尚未建立固定值；按本线深水故障情景、补货周期与维修策略继续评估”。跨线技术相容没有一个总答案，只对已经拿到资料的候选线路分别标记。至于“当前预先承诺调拨”，赛乌这一卷写的是：**无。实际请求到来时可按线路状态、技术相容、本线保障、补货与授权重新评估。**

这不是拒绝借。

也不是答应借。

它只是承认今天没有资格替未来某一次故障，提前把一段还在仓库里的线许给一个尚未发生的修复。

会散的时候已经五点十分。我原本四点半下班，工作靴里的左脚从下午开始一直有一点潮。我把样缆送回说明室，又回值班间签完交接。夜班的人看见桌上那张新表，问：“所以以后别的线断了，我们到底借不借？”

“到时候看。”

“开一天会就得出这个？”

“对。”

“那我现在就会。”

“你现在会的是四个字。你不知道到时候要看什么。”

她把表翻过来，看了半分钟。

“……好多。”

“嗯。”

“那还是你们开会吧。”

我终于去修鞋铺时，门口已经开始收遮雨棚。老板认识我那双靴子，接过去捏了捏鞋舌边缘，说不是大问题，内侧压条老化，明天下午取。她问我今晚穿什么回家，我才发现自己忘了带备用鞋。

最后她从柜台底下借给我一双店里给客人试底用的旧胶鞋。鞋大半号，走路时后跟会轻轻拍脚。我穿着它去市场买洋葱和两块鱼饼，路过旧港邮务柜台时，看见普通跨海电文的取件灯还亮着，就顺手问了一句有没有我的。

真有。

纸是灰岭转来的，排队时间不长，内容却让我站在柜台边上看了两遍。

**查到了。四十三年前《潮门》真的来过灰岭。她记得的半截船目前对应另一出戏，不能证明她把两次混在一起。今天先不查。——弥珞**

我不知道她为什么突然给我发这个。

大概因为我们以前在赛乌吃饭时聊过旧戏，也可能只是她觉得我会对“证据支持一半、另一半继续不知道”感兴趣。柜员问我要不要当场回，我说要，然后在小纸条上写了很久。

本来想写：

**我们今天也证明五百七十米不是五百七十米。**

写完自己都觉得像坏掉的算术，就划掉了。

最后我发的是：

**今天有人问仓库五百七十米备用缆能先答应借出多少。答案是现在不能先答应，但以后真有人需要还可以再问。你应该会喜欢。鞋明天才能修好。**

柜员看完，指着最后一句：“这个也发？”

“发。”

“和海缆有关系吗？”

“没有。”

她开始数计费字数。

我拎着洋葱和鱼饼离开柜台，旧胶鞋在石路上发出一点松松的啪嗒声。港池那边已经点灯，远处登陆站的窗只剩几格黄色，海线从岛边下水以后很快就什么也看不见。仓库里的那卷缆当然也没动，它还在木盘上，占着原来的地方，今晚不会去救任何人。

但账上已经多了一件以前没有的东西。

不是一百米，也不是五百七十米。

是一格允许人写：**现在不能先答应。**

我觉得这比提前填一个漂亮数字有用得多。
