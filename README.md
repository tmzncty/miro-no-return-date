# 弥珞没有返程日期

> 她还不知道自己的故事叫什么。

持续创作中的原创长篇小说。故事从一张没有返程日期的车票开始，逐渐展开到地方工程、生态、技术、档案、家庭、历史、国家与更大的世界。

## 仓库结构

- `chapters/`：逐章正文；**以这里的最新章节为正文准本**。
- `MANUSCRIPT.md`：定期整理的合并阅读稿。若与 `chapters/` 不一致，以分章正文为准。
- `canon/`：人物、关系、时间线、地点、国家、技术、古代史、组织和术语等连续性资料。
- `arcs/`：主要故事弧索引与阶段状态。
- `notes/`：伏笔、未来想法、连续性检查与文风约定。

**本仓库不保存原始聊天导出。** 仓库中的正文、设定与笔记均为整理后的项目材料。

## 创作与维护原则

- 正文以第一人称、弥珞的有限认知为主；人物拥有独立生活与视角，不围绕主角自动停止。
- 技术进步属于多人、机构与时代的共同结果，不写成弥珞个人发明史。
- 设定区分已发生、当前状态、推测与未知；“不知道”可以是正式答案。
- 时间会真正流逝。人物会长大，技术会过代，地点会在主角离开以后继续变化。
- 日常生活不是宏大叙事的填充物。吃饭、衣服、驾驶、工作、阅读、撒娇、休息与关系本身都是小说的一部分。
- 更详细的叙事约定见 [`notes/style-guide.md`](notes/style-guide.md)。
